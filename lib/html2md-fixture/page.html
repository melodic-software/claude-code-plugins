Widget configuration

Widgets read their settings from a settings file. See the CLI reference for every flag.

​
Install

Install the package and create a starter file:

npm install widget
widget --init --dir ./config

Options

NameDefaultDescription
timeout30Seconds before a request is abandoned.
modestrictEither strict | lenient.

Environment variables

  • WIDGET_HOME overrides the settings directory.
  • Set WIDGET_DEBUG=1 to log each request.
