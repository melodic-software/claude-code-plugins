## Core idea

Object writing is daily sensory diving. Start with a concrete object, then use
it as a trigger for sense memory rather than as a topic to explain. The goal is
not a polished lyric, a journal entry, or a story outline. The goal is fast,
specific, sense-bound language that lets the writer reach material only they
could have found.

> Your senses are driving the bus.

Skill behavior: when a user asks for "more vivid" lyrics, do not start by
adding adjectives. Start by asking what the speaker sees, hears, smells, tastes,
touches, feels inside the body, and feels through balance or motion.

## Show before you tell

Chapter 2 turns object writing into a placement rule: a lyric can tell the listener
what matters after it has first shown an image strong enough to color the
statement.

> Show before you tell.

Pattison frames the image as "Rusty's collar": the concrete thing the writer
holds up before explaining. A strong image placed early drips color downward
over the lines that follow. If the image arrives late, the opening statements
remain abstract and under-colored.

Use this diagnosis on bland drafts:

- Abstract line: names the feeling, lesson, topic, or conclusion.
- Rusty's collar: the concrete image that lets the listener feel that abstract
  line.
- Placement check: does the image appear before the statement it should color?
- Specificity check: does the image contain sensory or cultural detail, or is
  it just a general label?

The rule does not ban telling. It asks telling to earn its force by standing on
sensory evidence. "I miss home" can work after the listener has felt the hills,
trees, wages, weather, distance, or body motion of leaving. Without the collar,
the same claim becomes generic.

## Rusty's collar rewrite pattern

When a user brings a flat line, run this sequence:

1. Underline the direct telling: emotion, judgment, summary, or theme.
2. Ask what physical object, place, gesture, food, clothing, sound, or weather
   carries that feeling.
3. Generate three possible collars from object-writing material.
4. Place the strongest collar before the telling line.
5. Keep the telling line only if it gains force from the image.
6. If the telling still feels unnecessary, replace it with another image or
   action.

Useful coaching questions:

- What would the listener see before they knew what it meant?
- What object proves this feeling happened?
- Which specific detail turns the general place into your place?
- What line is trying to explain before the listener has been shown anything?
- If the image drips color downward, what should it be placed above?

## Cliche substitution warning

Chapter 2 also shows how replacing a specific image with a convenient general phrase
can weaken a lyric, especially when the substitution exists mainly to make a
rhyme work. If a draft swaps vivid place, job, weather, object, or body detail
for broad labels, keep the image and rework the rhyme.

Use [rhyme strategy](rhyme-strategy.md) and [rhyme types](rhyme-types.md) after
the collar is protected. The rhyme should serve the image, not erase it.

## The seven senses

Object writing uses seven sensory channels:

| Sense | Craft use |
| --- | --- |
| Sight | Color, shape, light, distance, motion, visual contrast. |
| Hearing | Texture, volume, rhythm, silence, muffling, resonance. |
| Smell | Atmosphere, memory triggers, environment, intimacy. |
| Taste | Appetite, disgust, sweetness, bitterness, temperature. |
| Touch | Surface, pressure, temperature, weight, pain, texture. |
| Organic | Inner body awareness: pulse, breath, stomach, muscles, fatigue. |
| Kinesthetic | Balance, speed, direction, body position, spatial relation. |

Organic and kinesthetic details are often the fastest way to move a lyric from
general description into embodiment. Use them when the draft explains emotion
from the outside instead of letting the listener feel it.

## Ten-minute practice

The basic practice is strict:

1. Pick a real object at random.
2. Set a timer for ten minutes, preferably first thing in the morning.
3. Write continuously in sensory language.
4. Move through all seven senses.
5. Follow sensory associations wherever they lead.
6. Stop immediately when the timer ends.
7. Mine the page later for images, phrases, titles, and emotional turns.

Stopping on time matters. The short container trains speed, access, and trust.
Object writing is a warmup and a source of material, not the whole songwriting
process.

## Loyalty to the object

The starting object is a diving board, not a contract. Stay loyal to sensory
motion, not to the literal prompt. If "puddle" leads to rubber boots, then
school hallways, then stomach tension before a childhood fight, follow the
senses.

Do not force:

- rhyme,
- meter,
- full sentences,
- chronological story,
- explanation of what really happened,
- cleverness,
- theme statements.

If a story appears because the senses pull the writer there, let it appear. If
it appears because the writer is trying to control the exercise, return to
specific sensory detail.

## What object writing is not

Object writing is not journaling. Journaling can explain, evaluate, remember,
or confess. Object writing stays inside sensory experience. It is also not a
drafting method for finished lyric sections. It generates raw ore: images,
verbs, physical details, surprising turns, and emotional weather.

When coaching, keep the user from turning the exercise into analysis. If a line
says "I was lonely," ask for the body, room, weather, object, taste, pressure,
sound, or movement that carries loneliness without naming it.

## Group and remote practice

Group object writing can build range because every writer enters the same word
through different sense memory. Use shorter rounds for larger groups and longer
rounds for small groups. Read aloud for image and sensory discovery, not
critique.

Object-writing parties can use:

- a warmup round,
- one or more ten-minute rounds,
- very short speed rounds,
- decompression rounds after intense writing.

Remote practice works by sending a daily object prompt and having writers reply
to the group. The useful part is rhythm and accountability, not performance.

## Expanded object writing

Once the writer has strong sense-bound habits, expand the prompt beyond objects:

- What: a thing, event, or scene.
- Who: a person, character, speaker, listener, or relationship.
- When: time of day, season, holiday, anniversary, age, era.
- Where: room, vehicle, street, stage, store, kitchen, border, doorway.
- How: process, movement, work, ritual, habit, or action.

"Why" is useful later, but it tends to pull writers into explanation too early.
Start with sensory access, then let meaning emerge.

## Challenge 1 practice frame

*Songwriting Without Boundaries* turns object writing into a 14-day curriculum.
The purpose is not to collect finished lyrics. The purpose is to train the
writer to enter material through sensory participation instead of observation.

> Sense-bound writing turns observers into participants.

Treat every daily prompt as a doorway into sense memory. The seed word may be a
thing, person, time, or place, but the working rule stays the same: get inside
the body, write quickly, follow sensory association, and stop at the timer.

## Strict timer and immediate access

Challenge 1 uses 5-minute, 10-minute, and 90-second writes. The timing is part
of the exercise, not a convenience. The writer stops exactly when the timer
ends, even mid-sentence or mid-word. This trains access under pressure and
keeps the practice small enough to repeat daily.

Use 90-second rounds when the writer is overthinking. The short window forces
verbs, body detail, and associative leaps before the censor can organize the
page into explanation.

Timer coaching:

- Before the timer starts, name the seed and the category.
- During the timer, follow the senses instead of staying loyal to the seed.
- At the buzzer, stop immediately.
- After the buzzer, underline the best images and verbs without rewriting the
  piece yet.
- If the page becomes abstract, restart with a physical sense: mouth, skin,
  breath, stomach, balance, pressure, temperature, sound, or motion.

## What, who, when, and where progression

Challenge 1 broadens object writing through four prompt categories:

| Days | Category | Function |
| --- | --- | --- |
| 1-5 | What | Enters through things, events, and scenes. |
| 6-8 | Who | Finds character through body, gesture, want, and environment. |
| 9-11 | When | Lets time, season, occasion, age, and moment color the senses. |
| 12-14 | Where | Uses place to organize action and make abstraction physical. |

This progression prevents "object writing" from becoming a narrow noun drill.
The same sensory engine can generate lyric raw material from a room, a person,
a holiday, a vehicle, a ceremony, or a place in motion.

Challenge 1 daily seeds:

| Day | Category | 5 minutes | 10 minutes | 90 seconds |
| --- | --- | --- | --- | --- |
| 1 | What | Sky | Crash | Lily Pad |
| 2 | What | Bathroom Mirror | Dentist | Screwdriver |
| 3 | What | Umbrella | Hair | Feather |
| 4 | What | Curb | Bouquet | Rain Cloud |
| 5 | What | Movie Theater | Cigar | Arrow |
| 6 | Who | Sailor | Waitress Clearing a Table | Priest |
| 7 | Who | Balloon Man | Homeless Child | Trucker |
| 8 | Who | Cyclist | Ballerina | Puppy |
| 9 | When | Summer Rainstorm | Graduation | Wedding Rehearsal Dinner |

Use these as models, not a mandatory canonical list. The category and timer
matter more than the exact seed word.

## Place as action organizer

The "where" days make an important adjustment: place is not scenery. A strong
where creates action, orientation, social pressure, weather, distance, acoustics,
traffic, smell, and bodily motion. If a lyric claims a general feeling, ask
where the body is when the feeling happens.

Where-writing repair questions:

- What can only happen in this place?
- What sounds, smells, or textures belong to this place and not a generic one?
- Where is the speaker's weight, balance, or line of sight?
- What is moving through the place: weather, traffic, people, music, light,
  heat, water, smoke, or memory?
- How does the place pressure the speaker into action?

## Post-write review

Review happens after the timer, not during it. Mine each timed write for:

- surprising verbs,
- sensory clusters,
- organic or kinesthetic details,
- place-specific nouns,
- possible titles,
- metaphor seeds,
- character wants,
- concrete images that could become Rusty's collar for an abstract line.

Do not polish the whole exercise. Pull the live material forward into lyric,
metaphor, rhyme, form, and prosody work.

## Character observation

Use "who" writing to support point of view and character work. Ask:

- Who is speaking?
- Who are they speaking to?
- What do they want?
- Why can they not say it directly?
- Which sensory details belong only to this person's body and world?

Observation games in public places are useful, but keep them ethical and
craft-focused. The point is to notice posture, pace, tension, gesture, objects,
distance, and implied want, then invent responsibly.

## Cataloging the good stuff

After each session, save the best lines, sensory images, title fragments,
verbs, object combinations, and emotional turns in a searchable notebook or
file. Do not stop the timed exercise to organize. Mine afterward.

Useful tags:

- title seed,
- verse image,
- chorus image,
- character detail,
- setting detail,
- organic detail,
- kinesthetic detail,
- metaphor seed,
- rewrite candidate.

## Chapter 1 exercises as coaching prompts

Exercise 1 - Seven-sense object writing:

- Pick a concrete object at random.
- Write sense-bound language using all seven senses.
- Do not rhyme, meter, outline, or explain.
- Afterward, mark the strongest sensory lines.

Exercise 2 - Timed "puddle" session:

- Set a ten-minute timer.
- Write on "puddle."
- Follow the senses away from the object if they pull you.
- Stop at the buzzer.

Exercise 3 - Timed "pepper" session:

- Set a ten-minute timer.
- Write on "pepper."
- Push beyond sight into taste, smell, touch, organic, and kinesthetic detail.
- Stop at the buzzer, then mine the page.

Chapter 2 - Rusty's collar rewrite:

- Choose one telling line from a lyric draft.
- List five sensory images that could prove or color the line.
- Put the strongest image before the telling line.
- Read the pair aloud and decide whether the telling now carries more weight.
- If the telling is redundant, cut it and let the image do the work.

## Skill workflow

When applying this file:

1. Ask for a concrete object if the user did not provide one.
2. Give a ten-minute, seven-sense prompt.
3. Tell the user to avoid rhyme, meter, story, and explanation during the timed
   write.
4. After the user shares raw writing, identify the strongest sensory details.
5. Sort found material into image, title, metaphor, character, and lyric-section
   candidates.
6. For a lyric draft, place the strongest image before the line it colors.
7. If the user wants a lyric, move from mined sensory material into form,
   prosody, rhyme, and repetition only after the object-writing pass is done.

## Prompt template

```text
Set a timer for 10 minutes.
Object: <object>

Write continuously using sight, hearing, smell, taste, touch, organic sense,
and kinesthetic sense. Follow sensory associations wherever they lead. Do not
try to rhyme, meter, explain, or finish a lyric. Stop when the timer ends.
```

Challenge 1 variant:

```text
Set a timer for <90 seconds | 5 minutes | 10 minutes>.
Category: <What | Who | When | Where>
Seed: <seed>

Write continuously in sight, hearing, smell, taste, touch, organic sense, and
kinesthetic sense. Follow sensory associations even when they leave the seed.
Stop immediately when the timer ends. Afterward, underline the strongest
images, verbs, body details, and metaphor seeds.
```

## Mid-word stop — non-negotiable

The single most-emphasized object-writing discipline across Books
2 and 3. When the timer ends, the writer stops where they are.

Not after finishing the word. Not after closing the thought. Stop.

> "Stop immediately when the timer ends." — Pat (*Writing Better Lyrics* (2009), Chapter 1;
> *Songwriting Without Boundaries* (2011), Challenges 1-4, paraphrased)

Reasons:

- The discipline trains the writer to trust the page over the
  desire to finish.
- Mid-word stops produce fragments that invite revision; finished
  thoughts feel closed and resist later mining.
- The timer is the exercise, not the writing. The writing is what
  the timer produces.

Coaching prompt at session open: "When the buzzer sounds, drop the
pen even if you are mid-letter."

## Destination writing — partial-tell integration

*Writing Better Lyrics* (2009), Chapter 1 names a refinement Pat returns to in lectures. Pure
object writing is fully sense-bound; destination writing
deliberately integrates a small amount of telling at the very end
of a sense-bound passage, so the page produces both raw material
and a partial direction.

Form:

```text
[ 8-9 minutes of sense-bound writing ]
[ 1-2 minutes of light interpretive line — a feeling, a turn ]
```

The shift happens late, never at the start. Telling at the start
forecloses sensory access; telling at the end uses the sensory
material to earn the interpretive line.

Use destination writing when:

- the writer's pure object-writing produces strong material but
  no usable lyric direction,
- a song idea exists but the sensory access feels thin,
- coaching a writer toward connecting raw material to song
  drafting.

Do not use destination writing as a default. Pure object writing
remains the primary daily practice. Destination writing is the
bridge from practice into drafting.

## Airport game — character observation

*Writing Better Lyrics* (2009), Chapter 1 introduces a character-observation drill Pat calls the
airport game. Useful for Who-category object writing (Days 6-8 of
*Songwriting Without Boundaries* (2011), Challenge 1).

Mechanics:

1. Sit in a public place — airport, café, train station, park.
2. Observe one person at a time.
3. From posture, pace, tension, gesture, objects carried, distance
   to companions, and clothing, infer:
   - what they want right now,
   - why they cannot say it directly,
   - what just happened to them,
   - what they are about to do.
4. Write a 90-second sensory pass on that person.
5. Keep ethical: invent responsibly; do not surveil; observe only
   what is visible in public.

Use the airport game when:

- a song needs a character the writer cannot imagine from scratch,
- a Who-category daily write feels generic,
- the writer is over-relying on their own life and needs external
  human material.

Pair with [point of view](point-of-view.md) when the character
becomes the song's speaker.

## Coaching prompts (extended)

- Did the writer stop the moment the buzzer rang? If not, the
  exercise was a draft, not access. Reset.
- Did the writer slip into explanation mode? Return to a specific
  sense (taste, body, touch).
- Is the writer mining the page or polishing it? Mining first,
  always.
- For destination writing: did the interpretive line earn its place
  by standing on the sensory material above it?
- For airport game material: is the character a real observation
  responsibly extended, or a projection? Real observation produces
  surprising verbs; projection produces generic adjectives.

## Kami-kazi — 90-second speed round (*Writing Better Lyrics* (2009), Chapter 1)

Pat names the 90-second object-writing variant the **Kami-kazi**, crediting
songwriter Kami Lyle for the technique. The name preserves the oral-history
texture of how the discipline developed inside Pat's Nashville writing
group.

The mechanics:

- 90 seconds, hard timer
- One seed word
- All seven senses on the table
- Stop mid-word at buzzer
- No editing during the timer

The brevity is the point. With only 90 seconds, the writer has no time to
deliberate — the seed has to launch into sensory association immediately.
Pat: the writus interruptus discipline trains depth across sessions; the
Kami-kazi compresses the discipline into the shortest viable window.

Use Kami-kazi as warmup before longer 10-minute writes, or as a standalone
when the writer has only a brief window.

## Object Writing Parties — Gillian Welch / Nashville Sunday format

Pat documents Gillian Welch's Nashville Sunday writing group as the
canonical Object Writing Party format. The structure:

1. **Warm-up** — informal arrival, no writing yet
2. **5-minute write** — first object write, picked seed read aloud
3. **10-minute write** — longer object write
4. **90-second Kami-kazi** — speed round
5. **Break** — 15-minute pause; no writing
6. **10-minute write** — second 10-min write
7. **90-second Kami-kazi** — second speed round
8. **5-minute write** — closing write, often a recombination of earlier seeds
9. **Share** — each writer reads ONE page (or part of one) aloud; no critique

The structure alternates timer lengths to keep access fresh — long enough
for depth, short enough to prevent over-editing.

The share phase has its own discipline: no critique, no praise that
qualifies criticism, no questions during reading. Pure listening. Critique,
if it happens, happens in private conversations after the group breaks.

Adapt for solo practice: drop the share phase, run the timer sequence on
your own, mine the pages afterward.
