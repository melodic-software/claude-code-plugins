# Fragment Development Prompt Template

Use when writer has a partial line / hook fragment / half-verse but can't
grow it.

## Step 1 — Inventory the fragment (writer-facing)

```
Read the fragment aloud once. Tell me:

1. Is it complete-shaped (a full line / couplet) or partial-shaped
   (a hook word / half-line)?
2. What position does it WANT to be in?
   - verse opener
   - verse close / refrain
   - chorus first line
   - chorus last line
   - bridge release
   - hook (title)
   - intro / coda / stand-alone scrap
3. What's strong about it? (image, sound, rhythm, twist, specificity)
4. What's missing? (context, image, who's speaking, why now)

Don't try to fix it yet. We inventory first.
```

## Step 2 — What does the fragment imply? (model-side, surface to writer)

```
The fragment implies more than it says. Pulling out what's already there:

- **Speaker:** <inferred POV>
- **Audience:** <inferred listener / "you" / self>
- **Time:** <present / past / ongoing / conditional>
- **Place:** <inferred setting>
- **Era:** <inferred decade / season>
- **Tone:** <controlled / raw / ironic / sincere / etc>
- **Genre proximity:** <country / folk / indie / hip-hop / etc>
- **Off-page moment:** <what's just happened that the fragment responds to>

Confirm or correct. We'll object-write the world this implies next.
```

## Step 3 — Object-write the implied world (writer-facing)

```
Set 10-minute timer. Object-write the world the fragment implies:
- the place specifically
- the moment specifically
- the speaker's body / hands / face
- the smells, textures, sounds
- the objects in arm's reach

Per Pat's seven senses. No lyric polish. Paste the page when done.
```

## Step 4 — Position the fragment (model-side)

Based on Step 1 position-tendency + Step 2 implications, the fragment fits
one structural role. Surface that role + the build-outward plan to writer:

```
The fragment fits as: <role>

To build outward:
1. <central section decision — chorus or refrain>
2. <draft central section if not yet present>
3. <draft section containing the fragment>
4. <draft remaining sections supporting fragment's role>
5. <prosody pass>
6. <rhyme pass>

Strongest material to preserve: <list 2-3 elements from Step 1 + the
object-write>

Strongest direction to take: <one-line>
```

## Step 5 — Draft the next section

Per the build-outward plan. Use object-write material from Step 3 as
vocabulary input.

## Step 6 — Pre-lock the fragment in context

Run `audit-checklist.md` per-line checklist on the fragment in its new
surrounding context. If the fragment changes shape to fit, that's healthy.

## Failure-mode prompts (use when the build stalls)

```
The fragment isn't growing yet. Try ONE of these:

- 20 more minutes of object-writing the world (sometimes there's not
  enough material yet)
- Move the fragment to a different position (verse opener → chorus close)
- Shift POV (1st → 2nd person)
- Shift tense (present → past)
- Set it aside for a week

Which feels right? Or tell me what specifically is resisting.
```
