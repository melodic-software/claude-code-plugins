# Object Writing Prompt

Use this prompt when the user wants a Pat Pattison-style daily sensory-writing
exercise. Choose one category and one timer; do not assign the whole
curriculum unless the user asks for a plan.

```text
Create one object-writing practice prompt.

Category:
<What | Who | When | Where>

Seed:
<specific seed word or phrase>

Timer:
<90 seconds | 5 minutes | 10 minutes>

Instructions for the writer:
1. Start the timer and write continuously.
2. Use sight, hearing, smell, taste, touch, organic sense, and kinesthetic
   sense.
3. Follow sensory associations even if they leave the seed.
4. Do not rhyme, meter, polish, explain, or try to finish a lyric.
5. Stop immediately when the timer ends.

After-writing mining:
- Underline 3 vivid sensory details.
- Mark 1 organic or kinesthetic detail.
- Circle 1 surprising verb.
- Save 1 possible title, image, or metaphor seed.
- Name 1 line that explains too soon and should be replaced with a physical
  detail.

Return format:

Prompt:
Category: ...
Seed: ...
Timer: ...

Write:
...

Mine afterward:
- Sensory details:
- Body/motion detail:
- Strong verb:
- Title/image/metaphor seed:
- Explains too soon:
```

Example seed:

```text
Category: Where
Seed: hotel bar
Timer: 90 seconds
```
