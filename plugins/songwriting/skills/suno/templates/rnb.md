# R&B template

Neo-soul leaning by default. For modern R&B / 90s R&B / alt R&B variants, swap descriptors.

## Style prompt

```
neo-soul, smooth and warm, soulful female vocals
with breathy delivery and ad-libs, vintage Rhodes piano,
laid-back groove, 78 BPM, Eb major,
no autotune, intimate room mic warmth
```

## Lyrics shell

```
[Intro]
[Verse 1]
Conversational, intimate first-person
Sensual / emotional imagery — touch, voice, eyes
Long phrases, melismatic-friendly

[Pre-Chorus]
Build vocally — climbing melodic line
Single phrase repeated with vocal runs

[Chorus]
[Female Vocal]
Title phrase, melismatic delivery
Title phrase, layered backing harmonies
Sticky hook, vocal runs on the last word

[Verse 2]
Deepen the emotional stakes from verse 1
More vulnerable, more confessional

[Pre-Chorus]
[Chorus]

[Bridge]
[Belted]
Strip to voice + Rhodes
Climb into the highest emotional register
Vocal runs and ad-libs
Build to the final chorus

[Chorus]
Final chorus — full ad-libs, layered backing
[Outro]
[Ad-libs]
Vocal improvisation over fading instruments
[Fade Out]
```

## Tweak knobs

- **Subgenre swap:** `neo-soul` → `90s R&B`, `modern R&B`, `alt R&B`, `quiet storm`, `gospel-influenced soul`, `funk soul`
- **Vocal:** `soulful female with breathy delivery` → `silky male falsetto`, `belted female with vocal runs`, `whispered intimate male`, `Aretha-style powerhouse`
- **Tempo:** 78 BPM (neo-soul default) → 65 BPM (slow jam) → 95 BPM (uptempo R&B) → 110 BPM (R&B-pop)
- **Production:** `intimate room mic warmth` → `polished modern R&B sheen`, `90s tape warmth`, `lo-fi alt R&B haze`
- **Lead instrument:** `vintage Rhodes piano` → `Wurlitzer`, `acoustic piano`, `nylon-string guitar`, `synth pad`

## Common variants

**90s R&B:** `90s R&B slow jam, NJS drum machine, lush synth pads, group harmony backing vocals, 75 BPM, Quiet Storm production, smooth and seductive`

**Alt R&B:** `alt R&B, hazy synth textures, sparse trap-influenced drums, intimate male falsetto, 85 BPM, lo-fi atmospheric production, dreamy and melancholic`

**Modern R&B:** `modern R&B, polished trap-soul drums, layered female vocals with runs, lush keys, 95 BPM, hyper-compressed mix, sensual and confident`

**Gospel soul:** `gospel-influenced soul, B3 organ, soulful choir, powerhouse female lead vocal, 78 BPM, Eb major, full live band feel, joyful and uplifting`

**Quiet storm:** `quiet storm R&B, smooth saxophone, electric piano, intimate male crooner, 70 BPM, late-night radio production, warm and intimate`
