# Jazz template

Smooth jazz / vocal jazz default. Standards-leaning ballad in Bb major.

## Style prompt

```
smooth jazz, upright bass walk, brushed drums,
breathy tenor sax solo, intimate male crooner,
90 BPM swing feel, Bb major,
vintage tube warmth, no electronic elements
```

## Lyrics shell

```
[Intro]
[Piano Solo]
Brief solo intro — 8 bars

[Verse 1]
Standards-style imagery — moonlight, longing, memory
Internal rhyme but conversational
Long phrases — jazz vocals breathe through them

[Chorus]
Title phrase, melodic, swing-friendly
Repeat with melodic variation
Land on the title word

[Saxophone Solo]
[Instrumental]
8-16 bars over the chorus changes

[Verse 2]
Develop the imagery from verse 1
Slightly more vulnerable

[Chorus]

[Bridge]
Key change up a half step
New melodic section

[Chorus]
Final chorus — vocal ad-libs over the top
[Outro]
[Fade Out]
```

## Tweak knobs

- **Subgenre swap:** `smooth jazz` → `bebop`, `cool jazz`, `vocal jazz`, `bossa nova`, `gypsy jazz`, `acid jazz`
- **Lead instrument:** `tenor sax` → `trumpet`, `piano`, `vibraphone`, `clarinet`, `guitar`
- **Vocal:** `intimate male crooner` → `breathy female contralto`, `Sinatra-style baritone`, `Ella-style scat`
- **Tempo:** 90 (ballad) → 120 (medium swing) → 180 (uptempo bebop)
- **Key:** Bb major (jazz standard default) → F major → Eb minor (modal)

## Common variants

**Bossa nova:** `bossa nova, nylon-string guitar, soft brushed drums, intimate Brazilian Portuguese female vocals, 120 BPM, warm room mic, no electric instruments`

**Bebop:** `bebop jazz, walking upright bass, ride cymbal swing, virtuoso saxophone leads, 240 BPM, mono recording, no vocals`

**Modern jazz:** `contemporary jazz, electric piano comping, fretless bass, complex chord changes, 100 BPM, polished studio mix, neo-soul vocals`

**Acid jazz:** `acid jazz, tight funk drums, electric piano vamps, sax stabs, 105 BPM, vintage analog mix, groovy and rhythmic`
