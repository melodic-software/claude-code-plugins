# Trap template

Modern trap with 808 sub-bass and triplet hi-hats. For boom-bap or conscious hip-hop see `hip-hop.md`.

## Style prompt

```
trap hip-hop, deep 808 sub-bass, hi-hat rolls and triplets,
mumbling melodic flow, 140 BPM, F# minor,
sidechain on pads, modern hyper-compressed mix,
no live guitars, no acoustic instruments
```

## Tweak knobs

- **Subgenre swap:** `trap hip-hop` → `melodic trap`, `dark trap`, `cloud trap`, `rage trap`, `Latin trap`, `Detroit trap`
- **808 character:** `deep 808 sub-bass` → `sliding 808s`, `distorted 808s`, `dry punchy 808s`
- **Flow:** `mumbling melodic flow` → `aggressive shouted flow`, `whispered flow`, `auto-tuned crooning`
- **Tempo:** 140 BPM standard → 70 BPM half-time feel (same 140 hi-hats, slow vocal) → 160 BPM rage trap
- **Mood:** `dark and menacing` / `triumphant and flexing` / `melancholic and reflective`

## Common variants

**Melodic trap:** `melodic trap, glassy bell synths, sliding 808s, auto-tuned crooning, 140 BPM, dreamy and longing, sidechain pump`

**Rage trap:** `rage trap, distorted 808s, screaming synths, aggressive shouted flow, 160 BPM, maximum compression, abrasive`

**Latin trap:** `Latin trap, dembow drum pattern, reggaeton-influenced 808s, Spanish male vocals, 95 BPM, party-energy production`
