# Metal template

Thrash metal default. Swap subgenre descriptors for death, black, doom, prog, melodic, metalcore, etc.

## Style prompt

```
thrash metal, down-tuned palm-muted guitars, blast beats and double-kick,
guttural growls, 200 BPM, E minor,
no clean vocals, raw analog recording,
aggressive and uncompromising
```

## Tweak knobs

- **Subgenre swap:** `thrash metal` → `death metal`, `black metal`, `doom metal`, `progressive metal`, `melodic death metal`, `metalcore`, `nu-metal`, `power metal`
- **Vocal style:** `guttural growls` → `black metal shrieks`, `clean operatic baritone` (power metal), `hardcore shouts` (metalcore), `mixed clean and harsh`
- **Tempo:** 200 BPM (thrash / death) → 60 BPM (doom) → 140 BPM (groove metal) → 180 BPM (melodic death)
- **Tuning:** `down-tuned` (drop C / drop B) → `standard tuning E` → `7-string drop A` → `8-string`
- **Mood:** `aggressive and uncompromising` / `epic and heroic` (power metal) / `crushing and slow` (doom) / `dissonant and atmospheric` (black metal)

## Common variants

**Death metal:** `death metal, blast beats, tremolo-picked riffs, guttural pig squeal vocals, 220 BPM, drop A tuning, brutal and technical`

**Black metal:** `atmospheric black metal, tremolo-picked guitars, blast beats, shrieked vocals, 180 BPM, lo-fi cold production, melancholic and ethereal`

**Doom metal:** `funeral doom metal, downtuned guitars, slow heavy chords, growled vocals, 60 BPM, crushing and oppressive, monolithic production`

**Power metal:** `power metal, soaring clean operatic male vocals, neoclassical guitar leads, double-kick, 175 BPM, epic and triumphant, polished mix`

**Metalcore:** `metalcore, breakdowns alternating with melodic clean choruses, hardcore shouts and clean vocals, chuggy guitars, 150 BPM, modern polished production`
