# Hip-hop template

Boom-bap leaning by default; for trap-leaning specifics see `trap.md`.

## Style prompt

```
boom bap hip-hop, dusty soul samples, head-nodding drum break,
upright bass underneath, conscious male flow, 88 BPM, F minor,
vinyl crackle, 90s NY warmth, no autotune
```

## Lyrics shell

```
[Intro]
[Spoken Word]
Short setup — one-line hook of the concept

[Verse 1]
[Rapped]
Sixteen bars, internal rhyme on every other line
Story-driven or concept-heavy depending on style
Use double meanings on key words for replay value
Hold the punchline for the back half of the bar

[Hook]
Title phrase, melodic delivery
Title phrase, repeat with backing ad-lib
Sticky, four bars, repeat-friendly

[Verse 2]
[Rapped]
Push the concept further, different angle
Reference verse 1 imagery for cohesion
Vary cadence — slow it down, speed it up
End on a setup line for the next hook

[Hook]

[Bridge]
[Melodic Rap]
Brief melodic moment
Stripped beat, signal section change

[Hook]
[Outro]
```

## Tweak knobs

- **Subgenre swap:** `boom bap hip-hop` → `conscious hip-hop`, `golden age East Coast`, `West Coast G-funk`, `cloud rap`, `drill`
- **Production era:** `90s NY warmth` → `2000s southern bounce`, `modern Atlanta polish`, `lo-fi chillhop`
- **Flow direction:** `conscious male flow` → `melodic rap`, `rapid double-time`, `slow drawl`, `aggressive battle flow`
- **BPM:** 88 (boom bap) → 75 (laid-back) → 95 (energetic) → 140 (trap, see trap.md)
- **Key:** F minor (default melancholic) → A minor (neutral) → C minor (dramatic)

## Common variants

**Lo-fi chillhop:** `lo-fi hip-hop, jazzy Rhodes piano, soft brushed drums, no vocals, 72 BPM, vinyl crackle, sleepy and warm`

**Drill:** `UK drill, sliding 808s, off-beat hi-hats, aggressive male flow, 140 BPM, dark and menacing, no melodic instruments`

**Conscious hip-hop:** `conscious hip-hop, live band feel, jazz piano comping, intricate male flow, 92 BPM, warm vinyl mix, no electronic drums`
