# EDM template

Festival-ready big-room EDM with build/drop structure. For dubstep specifically, swap descriptors below.

## Style prompt

```
big room EDM, massive supersaw leads, vocal chops,
build into euphoric drop, 128 BPM A minor,
festival reverb, sidechain pump, four-on-the-floor kick,
no acoustic instruments
```

## Lyrics shell

```
[Intro]
[Build]

[Verse 1]
Sparse, atmospheric, half-time feel
Anticipation building — sing-song melody
Set up the hook lyrically

[Pre-Chorus / Build]
[Build-Up]
Rising filter sweep, snare roll
Repeated single phrase, climbing pitch
"3, 2, 1" or wordless build

[Drop]
[Chorus]
Title phrase as the anchor
Vocal chops dance with the lead
Title phrase, repeat
Full rhythmic energy

[Verse 2]
Half-time again, atmospheric
Brief lyrical bridge — not narrative-heavy

[Build-Up]
[Drop]
[Chorus]

[Breakdown]
Strip everything back to vocal + pad
Final emotional moment before
[Build-Up]
[Drop]
[Outro]
[Fade Out]
```

## Tweak knobs

- **Subgenre swap:** `big room EDM` → `progressive house`, `tech house`, `future bass`, `melodic dubstep`, `trance`, `electro house`
- **BPM:** 128 (house/big room) → 138 (trance) → 174 (drum & bass) → 150 (dubstep half-time)
- **Drop character:** `euphoric drop` → `aggressive drop`, `melodic drop`, `bass-heavy drop`, `vocal drop`
- **Mood:** `festival anthem energy` / `dark and driving` / `euphoric and uplifting` / `melancholic future bass`

## Common variants

**Future bass:** `future bass, lush supersaw chords, vocal chops, syncopated drops, 150 BPM half-time, sidechain pump, dreamy and emotional`

**Drum & bass:** `liquid drum and bass, atmospheric pads, rolling breakbeats, rumble bass, 174 BPM, smooth and flowing, no four-on-the-floor`

**Dubstep:** `melodic dubstep, growly wobble bass, half-time drop, atmospheric vocal chops, 140 BPM, aggressive sound design, no live drums`

**Tech house:** `tech house, rolling bassline, percussive groove, vocal stab, 125 BPM, four-on-the-floor, club-ready dry mix`
