# Rock template

Guitar-driven rock. Default to grunge-leaning raw production; tweak for cleaner alternative or heavier styles.

## Style prompt

```
grunge rock, distorted Fender guitars, raw male vocals,
driving snare and tom fills, 4/4 135 BPM, A minor,
no synths, lo-fi rehearsal-room warmth
```

## Lyrics shell

```
[Intro]
[Guitar Solo]

[Verse 1]
Story-driven, conversational tone
Concrete details — places, objects, names

[Chorus]
Title phrase, full band, gang vocal feel
Title phrase, repeat with variation
Pay off the verse's tension

[Verse 2]
Escalate the conflict from verse 1
Same melody, new lyric direction

[Chorus]

[Bridge]
[Guitar Solo]
Stripped to bass and drums for first half
Big release in second half

[Chorus]
[Chorus]
[Outro]
[End]
```

## Tweak knobs

- **Subgenre swap:** `grunge rock` → `indie rock`, `garage rock`, `alternative rock`, `post-punk revival`, `pop-rock`
- **Era swap:** `lo-fi rehearsal-room warmth` → `90s alt-rock polish`, `70s classic rock analog warmth`, `2000s pop-rock sheen`
- **Guitar tone:** `distorted Fender` → `clean Telecaster jangle`, `palm-muted Les Paul crunch`, `fuzz-tone Big Muff`
- **Vocal:** `raw male vocals` → `clean female alto with rasp`, `shouted gang vocals`, `melancholic baritone`
- **BPM:** 135 (uptempo rock) → 90 (mid-tempo) → 160 (punk-leaning)

## Common variants

**Indie rock:** `indie rock, jangly clean Telecaster, melodic male vocals, pocket drums, 110 BPM, warm analog mix, no aggressive distortion`

**Stadium rock:** `arena rock, layered guitars, anthemic male vocals with reverb, four-on-the-floor 130 BPM, big chorus production, gated reverb on snare`

**Garage rock:** `garage rock revival, fuzzed-out guitar, sneering male vocals, sloppy live drums, 145 BPM, recorded-to-tape grit, no overdubs`
