## Core idea

Process means generating alternatives before deciding. Do not treat the first
workable draft as the song. Run the draft through the craft lenses until the
choice is informed rather than merely preferred.

> A metaphor has to be grounded in something real.

Chapter 24's case study starts with another writer's rough idea, then moves through
object writing, worksheet building, lyric restructuring, trigger-line revision,
point-of-view tests, tense tests, and form alternatives before the setting
process begins.

## Seed and lay of the land

Start by finding the song's center of gravity. In the chapter, the title image
is the productive place to begin because it is the centerpiece of the song.

First pass:

- Record or preserve the rough idea.
- Identify the title, refrain, or central image.
- Do object writing on that center before judging the lyric.
- Pull useful sensory material, metaphors, and scene possibilities from the
  object writing.

Object writing is not expected to be used whole. Its job is to reveal personal,
sense-bound material that can make the lyric more real.

## Worksheet as idea engine

Build an abbreviated worksheet from the current keywords. The Chapter 24 worksheet
uses `sea`, `shells`, `shore`, `sand`, and `tide`.

Use the worksheet to search for:

- Perfect rhymes that carry imagery.
- Additive rhymes that stay close to the sound.
- Consonance or family rhymes when the sound invites them.
- Subtractive rhymes when a consonant cluster can be loosened.
- Words that open useful scenes, not merely words that rhyme.

The worksheet is a brainstorming device first. If a rhyme word does not take
the song anywhere useful, reject it even when it is technically available.

## Draft order and cause

Before polishing lines, check scene logic. In the Chapter 24 draft, the reaction
appears before the action, so the opening order has to change.

Ask:

- What happens first?
- What does the singer or character react to?
- Does the listener know who each pronoun names?
- Is the scene inside, outside, remembered, imagined, or literal?

Confusion at this level cannot be solved by prettier language.

## Trigger lines

The trigger line is the line immediately before the chorus. It releases its
meaning into the chorus and determines how the listener hears the chorus.

Check it early:

```text
trigger line -> chorus meaning
```

If the trigger line is unclear, the chorus may be clear by itself but weak in
context. In the chapter, changing the lead-in makes the chorus become the
child's tiny melody instead of detached commentary.

## Grounded metaphor

Metaphors need a legitimate place in the scene. If the lyric is inside a house,
an ocean image can work only if the song has made that ocean present through
fantasy, memory, title, or point of view.

Use the grounding test:

```text
image:       what picture appears?
literal base: where can this image exist in the scene?
extra meaning: what else does it carry?
reader path:  how does the listener get there?
```

An image can be literal plus more. It fails when it is only writerly effect and
the listener has no contextual path into it.

## Immersion revisions

When revising a new version, read the whole lyric through rather than checking
only the changed lines. Local edits can appear sensible in isolation while
damaging the song's larger motion, point of view, or form.

Use a version pass for one main question at a time:

- Version for clarity.
- Version for elegance.
- Version for bridge angle.
- Version for point of view.
- Version for tense.
- Version for form.

This keeps revision from becoming random tinkering.

## Point of view and tense tests

Test every lyric from available points of view even when one seems obvious.
Chapter 24 tests third person, first person, and second person, then compares the
survivors side by side.

Decision factors:

- Intimacy.
- Immediacy.
- Whether the chorus still works.
- Whether the bridge flows into the chorus.
- Whether tense supports focus.
- Whether the speaker stays aimed at the strongest subject.

Do not forget future tense. A future-tense bridge can project consequence while
keeping present-tense verses immediate.

## Form alternatives

After point of view and tense are working, test form. Chapter 24's working form is:

```text
verse / verse / chorus / verse / verse / chorus / bridge / chorus
```

That creates the same risk identified in [song forms](song-forms.md): by verse
four, the listener has heard the same structure three times.

The chapter tests four options:

- Dump verse three or four if one can be removed without losing cause.
- Combine verses three and four into one tighter verse.
- Change the structure of verses two and four so the same shape does not repeat
  four times.
- Turn verses two and four into transitional pre-choruses before the chorus.

The chosen option is not "correct" because it wins an abstract rule. It wins
because it lets the second verse set up the chorus as both the child's song and
commentary, while letting the bridge word carry double meaning.

## Collaboration handoff

The lyric process does not end the song. Once the lyric alternative is chosen,
the setting process begins and the music may force radical change.

A durable handoff to a collaborator should include:

- The current best lyric version.
- Why that version won against the alternatives.
- The unresolved risks.
- The structural places the melody must protect.
- Permission for the setting process to change the lyric.

## Coaching prompts

- What is the title, refrain, or central image that deserves object writing
  before line editing?
- Which words belong in the first abbreviated worksheet?
- What does the trigger line make the chorus mean?
- Which image is attractive but not grounded in the actual scene?
- Which point of view has not been tested yet?
- What happens if the bridge moves into future tense?
- Which form alternative solves the repetition risk without losing necessary
  story?

## Revision workflow

1. Preserve the rough idea.
2. Identify the center: title, refrain, image, or scene.
3. Object-write the center.
4. Build a keyword worksheet for sonic and imagistic possibilities.
5. Reorder the draft for cause and clarity.
6. Repair pronoun references and scene logic.
7. Check the trigger line before each chorus.
8. Ground every metaphor in the scene.
9. Read each new version all the way through.
10. Test point of view.
11. Test tense.
12. Test form alternatives.
13. Compare pros and cons.
14. Choose the version that creates the richest supported resonance.
15. Hand the lyric into the setting process expecting further change.

## Common fixes

- If the chorus feels detached, rewrite the trigger line.
- If a metaphor feels clever but confusing, add or change the literal scene
  support.
- If the lyric loses immediacy, test present tense before changing imagery.
- If the narrator drifts, compare first, second, and third person side by side.
- If the form starts to feel long, run the same repairs used in
  [song forms](song-forms.md).
- If a collaborator dislikes a version, keep the process alive by generating
  the next grounded alternative rather than defending the first draft.
