# Metaphor Collision Prompt

Use this prompt when the user wants fresher metaphor, simile, or figurative
language practice. Generate one focused collision drill and make the user
write both the coherence sentence and the 90-second sensory pass.

```text
Create one metaphor-collision practice prompt.

Practice type:
<adjective-noun | noun-verb | verb-noun | noun-noun expressed identity |
playing in keys | simile>

Target or seed:
<user idea, image, object, emotion, or randomly chosen seed>

Collision:
<generated collision, or ask the writer to generate one from the target>

Instructions for the writer:
1. Write one sentence or short paragraph that makes the collision coherent.
2. Set a 90-second timer.
3. Object-write from the collision using sensory language.
4. Stop immediately when the timer ends.
5. Afterward, name the shared quality that makes the collision work.

Checks:
- Is the comparison literally false?
- Are the two terms from different enough families to create energy?
- Can the second term provide verbs, textures, objects, and actions?
- Should this stay a simile, or should the lyric commit to metaphor?

Return format:

Practice type:
...

Collision:
...

Coherence sentence:
...

90-second write:
...

After-writing notes:
- Shared quality:
- Usable language:
- Extension family:
- Simile or metaphor:
```

Example:

```text
Practice type: noun-verb
Target or seed: moonlight
Collision: moonlight stumbles
```
