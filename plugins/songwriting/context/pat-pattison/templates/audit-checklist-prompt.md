# Audit Checklist Prompt Template

Use when writer asks to pre-lock a line, a section, the title, or the
form. "Tools, not rules" — each box is a deliberate choice point, not a
gate. Naming a skip is fine; silent skips are not.

## Coach posture

- Walk the writer through the checklist applicable to their scope (line /
  section / title / form / song)
- For each box: present, ask, accept or note the skip reason
- Surface the dominant unresolved item; let the writer decide whether to
  fix or accept

## When to use which checklist

Confirm scope first:

```
What are you pre-locking?
- [a] A single line
- [b] A section (verse / chorus / bridge / refrain / TB)
- [c] The title
- [d] The form
- [e] The whole song (full audit)

Or paste what you want audited.
```

## Per-line audit walkthrough

For the chosen line, walk through each cluster aloud with the writer:

```
**Line:** "<the line>"

**Stress & meter** (Books 1 Chapter 3, 3 Chapter 4)
- [ ] Every stressed syllable on a strong beat?
- [ ] No greedy spots? (unstressed forced to strong beat, or stressed to weak)
- [ ] "into" handled per ínto rule (*Songwriting Without Boundaries* (2011), Challenge 4)?
- [ ] Compound words primary-stressed on first syllable?
- [ ] Grey-area stress flagged, not silently resolved?
- [ ] Sing-check passed?

**Rhyme stability** (Books 1 Chapter 4, 2 Chapter 4, 4 Chapters 4-6) — if rhyme position
- [ ] Identity check: pre-vowel consonants DIFFER?
- [ ] Stability tier chosen by emotional intent?
- [ ] No automatic cliche pair?
- [ ] Family-rhyme partners/companions inversion respected?
- [ ] Sing-check on rhyme position?

**Hot spots** (*Essential Guide to Lyric Form and Structure* (1991), Chapter 7)
- [ ] Section line 1: strong content word at start?
- [ ] Section last line: title or punchline-grade?
- [ ] Within phrase: second-most-important at start, most-important at end?
- [ ] No important content in unimportant grammatical positions?

**POV / address** (*Writing Better Lyrics* (2009), Chapters 10-13)
- [ ] Speaker consistent with section?
- [ ] No pronoun bouncing 1st/2nd/3rd?
- [ ] Hangman test passed? (direct address not telling "you" what "you" know)
- [ ] Camera distance matches section role?

**Image specificity** (*Writing Better Lyrics* (2009), Chapters 1-2)
- [ ] Rusty's-collar image before any telling line?
- [ ] No generic label substituting for concrete image?
- [ ] At least one sense in play?
- [ ] Verb doing the work (strong verb > adjective)?

**Cliche scan** (*Writing Better Lyrics* (2009), Chapter 5)
- [ ] No stale phrase?
- [ ] No predictable rhyme pair?
- [ ] No cliche metaphor family unreframed?
- [ ] If cliche used: is it "friendly" (earned by context)?

**Prosody** (*Writing Better Lyrics* (2009), Chapter 18-21)
- [ ] Motion (stable/unstable) supports emotion at this moment?
- [ ] Structure at line boundary aligns with content tension?
- [ ] Tone-of-voice stable?

Surface the FIRST checkbox that isn't checked. Don't run the whole list to
the writer at once unless asked.
```

## Per-section audit walkthrough

After running per-line on the section's lines, zoom out:

```
**Section:** <type — verse / chorus / bridge / refrain / TB>

**Section type diagnosis** (*Essential Guide to Lyric Form and Structure* (1991), Chapter 5)
- [ ] Section is doing the right job for its type
- [ ] Five-property test (lines / length / rhythm / rhyme / type) passes

**Five Compositional Elements**
- [ ] Number of lines counted
- [ ] Line lengths counted (stress count)
- [ ] Rhyme scheme (capital-letter notation per *Writing Better Lyrics* (2009), Chapter 19)
- [ ] Rhyme types per position
- [ ] Rhythm — duple / triple / mixed; consistent across like sections

**Stable / unstable**
- [ ] Section's lyric stability matches its melodic stability?
- [ ] Central section more balanced than outer sections?
- [ ] Bridge more unbalanced than verses?
- [ ] Transitional bridge most unbalanced of its system?

**Repetition** (*Writing Better Lyrics* (2009), Chapter 9)
- [ ] Chorus / refrain repaintable across visits?
- [ ] Verse 2 develops, not travelogues?
- [ ] Box-model weight rule: heaviest box last?
```

## Pre-lock-title walkthrough

```
**Sound**
- [ ] Stressed vowel identified?
- [ ] Family rhymes plausible? (internal generation + optional Datamuse)
- [ ] No automatic cliche partners?
- [ ] Front-/back-heavy noted?
- [ ] Stress pattern named (paradigm)?

**Meaning**
- [ ] Central idea in one sentence?
- [ ] Emotional shape implied?
- [ ] POV implied?
- [ ] One paragraph of "what the song is about" written?

**Form fit**
- [ ] Title repeats well → chorus form?
- [ ] Title lives once → verse/refrain or AABA?
- [ ] Hot-spot position chosen?
```

## Pre-lock-form walkthrough

```
- [ ] Central section chosen (chorus or refrain)?
- [ ] Title position decided?
- [ ] Repetition strategy: chorus repaints? refrain exact?
- [ ] Bridge present? — fulfills at least one *Essential Guide to Lyric Form and Structure* (1991), Chapter 5 function?
- [ ] "Four times is a lot" risk checked (*Writing Better Lyrics* (2009), Chapter 22)?
- [ ] Verse-job division clear (box model)?
```

## After the walkthrough

```
Unresolved items:
- <item 1>
- <item 2>

Dominant: <which one most affects emotional payoff>

Options:
1. Fix the dominant now
2. Accept the trade-off and note the skip reason
3. Defer and come back after another pass

Which?
```
