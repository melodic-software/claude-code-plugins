# Rhyme Worksheet Prompt

Use this prompt when the user wants help finding rhymes for a song idea, title,
verse, chorus, or rewrite. Adapt it to the user's material rather than asking
them to fill every field.

```text
Create a Pat Pattison-style rhyme worksheet for:

Title or working phrase:
<title>

Lyric idea:
<one-paragraph idea sketch, or infer one from the user's draft>

Tone:
<serious / playful / bitter / intimate / comic / other>

Section target:
<verse / chorus / bridge / refrain / unknown>

Process:
1. Focus the idea in one clear paragraph.
2. Extract 8-12 seed words from the title, emotional pressure, actions,
   relationship, images, and conflict.
3. Prefer seeds with varied vowel sounds.
4. For each seed, suggest rhyme candidates that fit the idea.
5. Label candidates as strong, usable with care, reject/watch, identity risk,
   cliche risk, or grammar risk.
6. Include idea paths opened by the strongest candidates.
7. Mark words that should probably stay out of rhyming positions.
8. End with 3-5 drafting notes for the requested section.

Return format:

Idea focus:
...

Seed words:
1. ...

Rhyme families:
Seed: ...
- Strong:
- Usable with care:
- Reject/watch:
- Idea paths:

Drafting notes:
- ...
```
