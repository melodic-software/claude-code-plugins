# Frontier: when a question is ready

A question is ready, and on the frontier, when it waits only on decisions whose answers would
change its framing or its option set; a question that waits on an unanswered one, including one
asked in the same round, is not ready, and one decision gates another only in that case. A
discovery or research item (where the code lives, what it does, a store inventory) holds back
only the questions that need its answer, never one the user can answer without it: the
acceptance-criteria coverage prompt, the problem, the users and the quality bar stay on the
frontier.
