# Page lane

SKILL.md's lane table routes here when `surface` is `page` or the user asks for the page. `<plugin-root>` is the placeholder SKILL.md "Spoke paths" defines. This file arrives unexpanded, so each `${user_config.KEY}` token below stands for the value SKILL.md's lane table shows for that key: put that value in its place. Page protocol: [`surface.md`](surface.md). The question shape and its rules every lane shares: [`question-shape.md`](question-shape.md).

**Question surface: the page.** Configured surface: **`${user_config.surface}`**. If it is `page`, start the page with the command below before the first round and ask no round inline. `page` selects a local page on 127.0.0.1 that this session watches; `terminal` is the default. A value other than `page` or `terminal`, or an unexpanded `user_config` token, falls back to `terminal`, with a one-line note only for a real unknown value. The page is two-way and is the input surface: the user answers each question there and every save reaches this session. The terminal stays a valid input, mirrored onto the page with `record-terminal`. A decision this session records or revises in the ledger is mirrored the same way. `surface: page` wins over `use_ask_user_question`, which applies only when the surface is `terminal`. The user may ask for the page at any point, whatever the setting. On a dense terminal round, offer the page; when the page cannot start, offer the read-only table. Start it with one command; the data dir sits in the memory slice, never CWD-relative:

```bash
bash "<plugin-root>/surface/round.sh" --dir '<memory_dir>/<topic-slug>/interview-surface' ensure-running --open --emoji-markers '${user_config.use_emoji_question_markers}'
```

Then write the frontier with `add-round` and arm the watcher as a background Bash task. Write the register's `open` rows in the same step with `round.sh --dir '<memory_dir>/<topic-slug>/interview-surface' sync-ledger --ledger '<memory_dir>/<topic-slug>/interview-checklist.md'` (the start command's `round.sh`), which rewrites the register rows from page state; the frontier-rounds contract (recommendation, basis, alternatives, probe, partial rounds, gates) holds on the page as it does inline. When Python, curl or bash is missing, the port cannot bind, the server stays unreachable after a restart (the watcher exits 2), or the session runs on a remote host the browser cannot reach, render the read-only decision table instead and say in one line which prerequisite failed. Substitution record: a value counts as set only when SKILL.md's lane table shows it substituted. A token the lane table shows literal is unset, whatever the key's saved state or `default`: `surface` falls back to `terminal` as above, and emoji markers fall back to off, since the start command passes the token through and `round.py` reads anything but true, 1, yes or on as off. Which values substitute into skill content: [manifest reference "Reference a saved value"](https://code.claude.com/docs/en/plugins/manifest-reference#reference-a-saved-value) and the `default` field of [User configuration](https://code.claude.com/docs/en/plugins/manifest-reference#user-configuration); our probe of an unset key with a `default` is the `/harness-ops:plugins` record "`userConfig`: an unset key renders the literal placeholder". As of 2026-10-27; recheck when either section changes, when that record is re-run on a newer release, or when a fresh-session probe records whether a saved boolean substitutes. A forced wrap-up names what it skipped: the `wrapup` event's text starts `Skipped before wrap-up:` (`round.sh status` prints it), and the wrap-up reports each skipped item to the user. Wake command, events, rules and wrap-up exports: [`surface.md`](surface.md).
