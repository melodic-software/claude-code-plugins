## Rules for instructions

Apply these to every task description and every log message.

- One instruction per sentence. One idea per sentence everywhere else.
- Split instructions longer than about 18 words, and other sentences longer than about 24.
- Put the warning or condition before the step it guards: "If the lock file is stale, the build can
  hang."
- Spell out a term once, then use the short form.

## Checking your work

Read the description aloud. Anything you stumble over is two sentences.
