Canonical location for the purposes of this case: `https://example.invalid/widget-runner/skills/release-notes/format`.

## Rules

- **One theme per release.** Two unrelated themes = two release notes
- **Concrete over abstract.** "Cache keys now include the runner version" beats "improved caching"
- **Push back on vagueness.** If the author cannot articulate WHY the change matters, interview them one question at a time before writing anything. A bad note is worse than no note
- **Revise when reality shifts.** Notes change. When a release slips, update it. Don't leave a stale note steering upgrades
- **Keep it short.** If the note runs past a screen, it stopped being a summary and started being a changelog
