# Consumer notes for generated playgrounds

Guidance for anyone using playgrounds generated by the upstream `playground` skill.
Each note restates an upstream fact, so each carries its pin: all were read from
`anthropics/claude-plugins-official` at commit `ed404106fcd80ba98ecb7c851e531dcb626d13b7`
(verified current on 2026-09-01). Recheck every note when the upstream repository moves
past that commit; the marketplace's native-surfaces registry carries the matching
recheck trigger.

## Theme your expectations

Generated playgrounds vary in theme support by template: the core guidance asks for a
dark theme, one template ships both light and dark styling, and another ships light
only. If a consistent theme matters for your use, say so explicitly in your prompt
("light and dark, honoring prefers-color-scheme") rather than assuming a default.

## Sanitize what you feed a data explorer

The data-explorer template renders query text through regex-based highlighting into
`innerHTML` without escaping. Feed it only content you trust. If you adapt that
pattern for anything that displays untrusted input, add HTML escaping before it goes
near `innerHTML`.

## Expect some prompt-output gaps

The document-critique template's prompt generator emits its approved-improvements
group; its additional-feedback and rejected-with-context groups are placeholders at
the pinned commit. If your workflow depends on rejected items reaching the prompt,
copy them manually or say in your generation prompt that all three groups must be
implemented.

## The output prompt is the product

A playground's value lands when its generated prompt is pasted back into the session.
Before a long exploration, press the copy button once and paste the result to confirm
the round trip works in your environment (clipboard access can be restricted inside
sandboxed pages).
