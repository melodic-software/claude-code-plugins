# Architecture decision records

Decisions that shaped this service live here, one file per decision.

## Naming

`NNNN-kebab-title.md`, where `NNNN` is a four-digit zero-padded number. The next
record takes the highest existing number plus one.

## Sections

Every record carries these five, in this order:

- `## Status` (one of `Proposed`, `Accepted`, `Rejected`)
- `## Date`
- `## Context`
- `## Decision`
- `## Consequences`

Keep each section to a few sentences. A record that needs more than a page is
usually two decisions.
