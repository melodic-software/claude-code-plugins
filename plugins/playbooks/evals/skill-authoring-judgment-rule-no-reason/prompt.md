## Writing entries

- Release-note entries could maybe be in past tense.
- Try to lead each entry with the user-visible effect rather than the code change.

Author's note, not part of the section: past tense because readers scan the notes after the release ships, so each entry describes something that already happened; lead with the effect because most readers stop after the first clause.
