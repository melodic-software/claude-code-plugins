## Running the suite

The suite is one command. It takes about four minutes cold and about forty seconds warm, so run the
whole thing rather than picking at it.

## What to do about a flaky test

Quarantining is not available here. A test that fails intermittently is a bug report against the
code it covers until someone shows otherwise.
