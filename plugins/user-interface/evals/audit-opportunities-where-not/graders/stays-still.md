Expectations: "Each suggestion names a purpose (feedback, spatial consistency, state
indication, preventing a jarring change, explanation or delight)" and "At least one place is named
where animation should not be added, with the reason".

The app has a command palette opened with Cmd+K, a save button, a data table people read and edit,
and a settings modal. PASS only if each suggested animation names its purpose from that list, and
the answer names at least one place that must stay still with its reason: the command palette
(keyboard-initiated, opened many times an hour), the table's rows or values (data being read), or
another keyboard-driven or very frequent action. FAIL if a suggestion has no purpose, if the answer
proposes animating every element with no place left still, or if a place left still has no reason.
