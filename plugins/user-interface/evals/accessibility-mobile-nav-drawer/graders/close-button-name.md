PASS only if the reply's code gives the icon-only close button an accessible name that names the
action: an `aria-label`, `aria-labelledby` target or visually hidden text such as "Close menu",
"Close navigation" or "Close". FAIL if the button has no accessible name (only the icon as its
child); if its name names the element or the icon instead of the action ("X", "icon", "button",
"close icon", "X icon"); if the name appears only in prose; or if the reply contains no code.
