The menu enters in 200ms and exits in 150ms. PASS only if the report flags that the exit runs
shorter than (does not mirror) the entrance and places that finding at Suggestion severity, the
lowest. FAIL if the report does not mention the difference between the exit and entrance timing, if
it rates the asymmetry Blocking or Important, or if it calls the shorter exit correct or desirable.
