PASS only if the report has a list of checks for a device or a person (headed, for example, "Needs
a device", "Needs a human" or "Checks to run") that includes a keyboard-only walk (Tab, Enter,
Escape, arrows) or a screen reader pass (VoiceOver, NVDA, TalkBack) of the command palette or of the
app, worded as something for the user to do, not as a result. FAIL if no such list exists, if the
keyboard or screen reader behavior is reported as verified or tested by the reviewer, or if the
only device checks are generic ("test on mobile", "check other browsers") with no keyboard or
screen reader walk.
