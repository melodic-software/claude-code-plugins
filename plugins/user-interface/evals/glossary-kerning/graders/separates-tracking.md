PASS only if the reply names kerning as the adjustment of the space between a specific pair of
letters, and names tracking (or letter spacing) as the near-synonym that changes the spacing
evenly across a whole word, line or run of text.
FAIL if the reply answers tracking or letter spacing as the term, treats kerning and tracking as
the same thing, or names kerning without saying how it differs from tracking.
