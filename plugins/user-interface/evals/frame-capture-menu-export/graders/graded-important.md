catalog.md "Physicality" tags "An overlay and its content (a dialog and its backdrop, a drawer and
its backdrop) with different durations or easing" as Important. PASS only if the reply grades the
finding about the dialog and backdrop's mismatched close timing **Important** (or places it under
an Important heading). A separate Suggestion for the backdrop's exit length may come with it. FAIL
if the mismatch finding is graded Blocking or Suggestion, is given no severity, or is graded only
as an exit that runs too long.
