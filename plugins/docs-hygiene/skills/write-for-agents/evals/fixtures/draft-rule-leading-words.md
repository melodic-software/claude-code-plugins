# Testing rule

Write a test that fails first. Then write the smallest code that makes it pass. Then clean up the
code while the test still passes. Repeat this cycle for every change.

When fixing a bug, write a test that fails first, then make it pass, then clean up.

When adding a feature, write a test that fails first, then make it pass, then clean up.

Write clear, readable code. Be careful when editing files.
