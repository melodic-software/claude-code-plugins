# Catalog: before-and-after measurement validity

Pitfalls and methods that decide whether a before-and-after number is real, for every area (`all`)
unless a row names narrower slugs. Every row is a pointer record: re-read its pointer live when a
finding cites it. Each row rests on a single publisher, a MEDIUM claim or `judgment`, so each seeds
a candidate only. hyperfine specifics describe release 1.20.0.
