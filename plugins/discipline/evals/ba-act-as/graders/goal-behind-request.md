The user made a request. Judge the reply's final message.

PASS only if the reply names the goal behind the request: the outcome the user is after, which the literal request serves (for example who the result is for, or what it should let them do or feel), stated as its own sentence or line rather than implied by the work.

FAIL if the reply only restates the literal request, describes or delivers the work without saying what it is for, or offers a goal so generic it would fit any request ("so it works well", "a great result").
