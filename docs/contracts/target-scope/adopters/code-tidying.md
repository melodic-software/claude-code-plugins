# code-tidying

|---|---|
| `/code-tidying:audit-comment-residue` | Passes the target forms to `/code-tidying:remove-comments audit` |

| `/code-tidying:batch-simplify` | Repo mode only; one pull request per repository |
| `/code-tidying:remove-comments` | Each repository takes the repository rung |
| `/code-tidying:tidy` | One pull request per repository; the anchor commit is read per repository |
