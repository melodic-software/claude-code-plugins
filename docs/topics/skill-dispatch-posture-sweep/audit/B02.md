Criteria: [`../LEDGER.md`](../LEDGER.md).
Decisions: [`../../discovery-subagent-dispatch/PLAN.md`](../../discovery-subagent-dispatch/PLAN.md).

**Verdict rule applied:** the **bare/default invocation path** governs the verdict — the Brief's
acceptance criteria are all framed as "invoking `/<skill> <args>` with no other arguments". Per-action
splits in a multi-action skill are recorded in the Rationale, not by splitting the verdict.

Mechanism is `—` for every `NO-CHANGE` and `INLINE-ONLY` row (not blank — blank reads as unaudited).

## Notable

**`allowed-tools` on a preloaded skill is an unresolved harness question.** The Brief enumerates the
subagent frontmatter fields and both tool filters but is silent on whether a *skill's*
`allowed-tools` grant survives a `skills:` preload inside a subagent. It matters because a background
subagent cannot answer a permission prompt — a grant that does not carry would turn a pre-approved
`Bash` call into a hard failure rather than a prompt. Three B02 skills declare one
(`audit-comment-residue`, `tidy`, `context7:lookup`), but only **`audit-comment-residue`**'s verdict is
sensitive to it; the other two are INLINE-ONLY / NO-CHANGE on independent grounds. Flagged for the
plan step, not resolved here.

**`disable-model-invocation: true` clusters on the mutating operator skills.** Both `claude-ops:lanes`
and `claude-ops:plugins` set it, and in both cases it independently rules out the plugin-agent
mechanism (no `skills:` preload). Neither wants dispatch on other grounds, so the flag costs nothing
today — but it means "flip the flag" is a prerequisite, not a detail, for any future reconsideration
of these two.

**"Print the script's output verbatim" is a recognizable NO-CHANGE shape.** `lanes` and
`morning-brief` both delegate their whole contract to a bundled script and declare its stdout the
deliverable. There is no model-generated intermediate content to summarize, so dispatch has no
context to save — it only adds a hop. Worth naming as a reusable disqualifier for the remaining
batches, since several `claude-ops`-style operator skills share it.
