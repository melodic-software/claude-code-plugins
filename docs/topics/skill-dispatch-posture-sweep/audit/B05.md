## Notable

- **Frontmatter is a null result.** No `disable-model-invocation: true`, no `context: fork`, no
  `agent:` anywhere in B05 — so `skills:` preload is available to every dispatch candidate here with
  no flag change. (`machine-health:audit` carries only `name` + `description`; the rest are
  `disable-model-invocation: false` or omit the field.)

- **The three `knowledge:` skills are prior art, not targets.** Decisions 4/5/6 already exist in
  built form — `book-distill`'s File-plan table, `youtube-digest`'s `watch-checklist.md` plus its
  blocking `check-watch-outcomes.js` gate, and both skills' hub-over-shards artifact sets. Recommend
  the `discovery:researcher`/`discovery:explorer` definitions borrow `youtube-digest`'s
  ledger-plus-verify-script shape rather than inventing one. `course-digest`'s gap is narrow: its
  checklist exists but carries no per-item depth criterion.

- **Action-router skills need per-action verdicts.** `kindle-dedrm:manage`, `course-digest`, and
  `youtube-digest` each hold actions on opposite sides of the line (`manage update` read-only vs
  `manage cleanup` per-item Y/N; `watch` multi-hour vs `queue list` a table print). One verdict per
  skill either over-dispatches trivial actions or blocks the expensive one — the sweep's output shape
  may need a per-action column.

- **`!`-injection under `skills:` preload is unverified and load-bearing.** `implement`,
  `course-digest`, and `youtube-digest` (all `shell: bash`) probe the environment at load time; the
  latter two **STOP** on those probes ("STOP if pre-computed context shows MISSING"). Whether the
  substitutions execute when a skill is preloaded via a subagent's `skills:` frontmatter — versus
  invoked through the `Skill` tool — is not addressed in the Brief's constraints and I did not test
  it. Verify before authoring agent definitions.

- **`implement-dispatch` is a structural inversion, not a blocked skill.** Its "worker returns are
  synthesis, not ground truth; promote their claims to direct evidence before building on them" is a
  discipline the Brief's pointer-plus-summary contract owes an answer to: a parent that reads only
  the summary is accepting synthesis as ground truth, which this skill forbids.
