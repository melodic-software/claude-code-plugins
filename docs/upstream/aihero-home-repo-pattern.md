# Upstream source: AI Hero, "The Home Repo Pattern" (Matt Pocock)

This page records what this repository takes from, adapts, already has, or rejects in
[The Home Repo Pattern](https://www.aihero.dev/the-home-repo-pattern) (no license found, ideas
only), together with its companion
[video](https://www.youtube.com/watch?v=hWe-j78vNpc), the
[dictionary entry](https://www.aihero.dev/ai-coding-dictionary/home-repo) the page links, and the
author's two posts announcing it
([first](https://x.com/mattpocockuk/status/2120260969750540327),
[second](https://x.com/mattpocockuk/status/2120838662254420341)) with their replies. Rows hold our
decisions and our own descriptions of each idea, under the upstream-drift convention's
[What a row may describe](https://github.com/melodic-software/claude-code-plugins/blob/main/docs/contracts/upstream-drift/README.md#what-a-row-may-describe).
The repository owner set every disposition on 2026-11-12 or 2026-11-13; this record states them.
The decision itself is recorded in the organization's private architecture repository.

The estate this record speaks for is wider than this repository: the marketplace here, the
owner's user-scope dotfiles, the standards sync, and the organization's custom properties. A row
names the surface in this repository where one exists and says so when the owner is elsewhere.

- **Pointer**: when a row's idea needs its upstream wording, fetch the section the row links
  live; correlate with the video, the dictionary entry and the posts linked above. The page
  anchors its sections and its FAQ groups, not single questions, so a row about one question links
  its group and names the question. No docs page covers the hub pattern itself; where a Claude
  Code docs section governs a row, the row links it.
