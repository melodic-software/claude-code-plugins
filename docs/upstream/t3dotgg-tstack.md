# Upstream source: t3dotgg/tstack

This page records what this repository takes from, adapts, already has, or rejects in
[t3dotgg/tstack](https://github.com/t3dotgg/tstack) (MIT), nine agent skills for the pull request
lifecycle. Rows hold our decisions and our own descriptions of each idea, under the upstream-drift
convention's
[What a row may describe](../contracts/upstream-drift/README.md#what-a-row-may-describe); read
upstream at each row's link for what it says.

**Last audited upstream state:** `t3dotgg/tstack@1085050f3baed1ac724caa4a8166145fb2ac88af` under `skills/` (committed 2026-10-28, no tags or releases).

**Recheck trigger:** a change, between the pinned commit and upstream HEAD, to a path a row we took
or rejected something from links, a unit removed or added under the scope: re-audit the affected
rows.

**Adaptation posture.** Nothing here is vendored. Six of the nine skills cover ground the
`source-control`, `work-items` and `verification` plugins already own, so a row either names that
surface or says why the idea stays out. Two rules shape every row:

- **Authority stays in tracked config and the permission system.** A trigger phrase grants nothing
  in this marketplace; what a run may do comes from `AGENTS.md`, each repository's conventions and
  the permission mode.
- **Claims about review value rest on measurement.** The fan-out reviewer-diversity evals
  ([#12151](https://github.com/melodic-software/claude-code-plugins/issues/12151#issuecomment-6588001580),
  [Codex arms](https://github.com/melodic-software/claude-code-plugins/issues/12151#issuecomment-6593273287))
  set the council's defaults. Recall in those evals sits at ceiling, so they show no gain from more
  models on these fixtures and cannot show that none exists on harder changes.
