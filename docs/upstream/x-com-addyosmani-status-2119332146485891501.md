# Upstream source: Addy Osmani, "Your coding agents made you a manager"

This page records what this repository takes from, adapts, already has, or rejects in
[Addy Osmani's X Article "Your coding agents made you a manager"](https://x.com/addyosmani/status/2119332146485891501)
(published 2026-11-08; no license found, ideas only). Rows hold our decisions and our own
descriptions of each idea, under the upstream-drift convention's
[What a row may describe](https://github.com/melodic-software/claude-code-plugins/blob/main/docs/contracts/upstream-drift/README.md#what-a-row-may-describe).
The repository owner set every disposition in an interview on 2026-11-09; this record states
them.

Most of the post's Claude Code advice follows the
[Claude Code best-practices page](https://code.claude.com/docs/en/best-practices) section by
section, so a row whose topic that page or another docs page covers points there, and the post is
the correlate.

- **Pointer**: when a row's idea needs its upstream wording, fetch the docs section its **Stated**
  link names live; correlate with <https://x.com/addyosmani/status/2119332146485891501> (an X
  Article has no section anchors, so each row names the article section it comes from). No docs
  page covers the management-framing, metrics and what-not-to-build rows.
