# Upstream source: Addy Osmani, "Critical thinking when agents do the work"

This page records what this repository takes from, adapts, already has, or rejects in
[Addy Osmani's X Article "Critical thinking when agents do the work"](https://x.com/addyosmani/status/2117512471930167377)
(published 2026-11-03; no license found, ideas only). Rows hold our decisions in our own words;
read the post at each row's link for what it says. The repository owner set every disposition in
