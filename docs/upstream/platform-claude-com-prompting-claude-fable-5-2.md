# Upstream source: "Prompting Claude Fable 5.2" and "What's new in Claude Fable 5.2"

This page records what this repository takes from, adapts, already has, or rejects in two
Anthropic docs pages for Claude Fable 5.2, the
[Prompting Claude Fable 5.2](https://platform.claude.com/docs/en/build-with-claude/prompt-engineering/prompting-claude-fable-5-2)
guide and
[What's new in Claude Fable 5.2](https://platform.claude.com/docs/en/models/fable-5-2/whats-new-fable-5-2),
with one staff post as a second source. Rows hold our decisions and our own descriptions of each
idea, under the upstream-drift convention's
[What a row may describe](https://github.com/melodic-software/claude-code-plugins/blob/main/docs/contracts/upstream-drift/README.md#what-a-row-may-describe);
read upstream at each row's link for what it says. No figure from either page is recorded here:
each row links the section that holds its measurement.

The surfaces judged are the Fable 5.1 doctrine in `plugins/playbooks/skills/fable-5/` (`SKILL.md`
and `context/*.md`) and the chapters in `plugins/playbooks/reference/model-adaptation/`. The owner
decided that the 5.1 doctrine stays and that a links-only chapter,
`plugins/playbooks/reference/model-adaptation/fable-5-2.md`, carries every `take` and `adapt` row
below. That chapter is not written by this record.

  live. Row W1 cites the text above the first heading, which has no anchor, so it links the page top.

  fallback), fetch [Model configuration](https://code.claude.com/docs/en/model-config) at the
  anchor the row names, live.

- **Pointer**: when an `A` row needs the post's tip, fetch
  <https://x.com/alexalbert__/status/2119869724247077229> live (Alex Albert, Anthropic staff,
  posted 2026-11-09). Each `A` row names the docs section that covers its topic as the main

anything about their content.

## Row schema

**ID**: `G` rows come from the guide, `W` rows from the What's new page, `A` rows from the post,
`M` from model currency. The chapter cites these IDs. **Stated**: the upstream gives this problem
where the label's link points. **Inference**: we derived it from the mechanism. **Doctrine section**
names the section of the 5.1 doctrine or another surface that the row adjusts, narrows or
reverses, or `none`.
