## Two standing rules

1. **Re-measure, do not re-cite.** This applies to the hook budget above all: the
   published reference figures predate a 69% growth in wired entries and seven
   unpulled performance commits.
2. **A readiness check based on `claude plugin --help` or on the docs returns a
   false negative.** `claude plugin test` is a working but hidden, gate-registered
   command, and the docs have never named the feature. Probe behaviour, not help
   text.
