# Review criteria

This repository's review rules that CI does not enforce, one file per concern. Read the files whose
concern a change touches; each line names a rule, and its link states the rule in full.

| File | Applies when the change touches |
|---|---|
| [`REVIEW.md`](https://github.com/melodic-software/standards/blob/main/REVIEW.md) | anything: org-wide criteria, read from `melodic-software/standards` main |
| [`findings.md`](findings.md) | anything: how many findings one review posts |
| [`skills-and-agents.md`](skills-and-agents.md) | skill or agent text, or a standing instruction |
| [`cost-claims.md`](cost-claims.md) | a cost, price or pricing claim |
| [`comments.md`](comments.md) | comments in code |
| [`evals.md`](evals.md) | eval cases, or a change that needs or runs an eval |
| [`hooks.md`](hooks.md) | a hooks module or a hook's matching |
| [`untrusted-content.md`](untrusted-content.md) | text read from web pages, tracker items or tool output |
| [`pull-requests.md`](pull-requests.md) | work on an open pull request |
| [`linters.md`](linters.md) | a linter or formatter version, or its configuration |
| [`tests.md`](tests.md) | a test whose fixture stands in for another program's output |
