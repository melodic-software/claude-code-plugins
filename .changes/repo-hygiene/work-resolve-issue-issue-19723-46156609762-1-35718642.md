### Fixed

- **A batch clean on Windows honors a skip-list entry whatever path form it is written in.** `clean_path_key` now converts an absolute POSIX-form path, such as `/tmp/x` or `/c/<user>/x`, to its drive form with `cygpath -m` on MINGW, MSYS and Cygwin hosts. A skip-listed clone is no longer cleaned, and the next clone of the same origin runs in its place ([#19723](https://github.com/melodic-software/claude-code-plugins/issues/19723)).
- **The `batch-common`, `clean-batch`, `git-stash-audit` and `git-noninteractive` test suites create their temporary root through a shared `test_native_path` helper.** Their expected paths now match the drive form the scripts print on Windows, and the stub directories they put on `PATH` keep the POSIX form, since a drive colon would split a `PATH` entry. The `batch-common` suite's `cygpath` stub is an executable in such a directory, found the way the real one is, so it needs no shellcheck suppression.
