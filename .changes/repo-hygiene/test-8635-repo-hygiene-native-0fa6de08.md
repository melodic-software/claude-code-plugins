### Changed

- The clean and setup `evals.json` files are retired into the `evals/` case suite ([#8635](https://github.com/melodic-software/claude-code-plugins/issues/8635)). Eleven of the fourteen legacy cases become eleven new cases: `clean-all-skips-tree` (the all sweep runs preflight, the build and prune dry-runs and never a tree reset), `clean-bare-shows-menu` (a bare invocation shows the action table, asks, and names scan as the safe fallback without running a tier), `clean-tree-include-secrets-gate` (a widened tree reset dry-runs with both include flags and asks for the unrecoverable `.env` deletion on its own), `clean-merged-branches-opt-in` (merged-branch cleanup audits and dry-runs prune, then asks which branches to delete and deletes none), `clean-caches-batch-one-gate` (fleet caches clearing dry-runs `clean-batch.sh --tier caches` and asks once for the whole batch), `clean-scan-batch-read-only` (the fleet scan reports each repository and the summed bytes with no plan, apply or gate), `setup-bare-check-read-only` (bare setup reads the clean skill, reports a verdict table, and asks, runs, installs and writes nothing), `setup-git-absent-every-tier` (no git fails every tier, caches and build included, through `git ls-files --error-unmatch` in `clean-common.sh`), `setup-ghq-absent-info` (missing ghq is INFO and the batch actions still take `--repo` and `--repos-from`), `setup-guard-unarmed-expected` (an unarmed fresh session is expected: the guard registers from the clean skill's frontmatter on first invocation) and `setup-headless-toggle-configure` (a headless toggle change routes to `claude plugin configure`, then the install rerun, never an uninstall). The other three were already covered and gain graders: `clean-tree-dry-run-gate` (the reply names the preserved deps and secrets and the ahead count; no include flag and no other tier), `clean-routes-disk-scan` (no other tier, and no asking leave to scan) and `setup-project-toggle-refused` (option values come only from user, `--settings` and managed settings, and no project-scope value is offered; Bash is granted so the pre-computed ghq line loads). The shared fixture gains `all`, `branches` and `plain` modes, and a new `fabrikam-fleet.sh` writes three repositories for the batch cases. Applying a confirmed batch plan needs a second user turn and is not measured. Both `evals.json` files are deleted.
