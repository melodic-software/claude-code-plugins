### Changed

- `plugin.json` declares the mods floor as `engines["claude-code"]`, `">=2.1.287"`. Claude Code 2.1.323 and later read it and do not install, update or load the plugin outside that range; 2.1.76 through 2.1.322 ignore it, so the settings hook still runs there, and 2.0.15 through 2.1.75 refuse to load a manifest that has it.
