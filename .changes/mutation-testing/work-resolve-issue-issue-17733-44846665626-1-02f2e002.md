### Changed

- The audit skill no longer ships per-runner `test-command` forms for vitest, jest, mocha, Maven, Gradle, PHPUnit, pytest or unittest. Its "`test-command` filter forms" section now defines the path-list and name-filter-only kinds and says to read a runner's kind from the repository's test configuration and the runner's own help or documentation. A runner whose kind stays unknown counts as name filter only, as an unlisted runner did before. The `dotnet test` row, which the bundled `dotnet-test-selection.sh` drives, stays. Setup's runner-support step reads the kind from that section.

- The audit skill drops its StrykerJS `inPlace`, Hypothesis and fast-check pointers, the .NET example in the never-guess-the-test-command rule, the `src/pricing.ts` path in the sample suppression entry, and the file-type examples in the persist-findings source-root heuristic.
