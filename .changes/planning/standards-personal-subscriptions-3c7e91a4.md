### Added

- Standards resolution reads personal subscriptions, standards contract 1.3.0: the repositories the user-global index lists in `standards_repositories`, each a personal layer beneath the user's own standards files and every team-tracked one. `scripts/org-standards.sh subscriptions` prints each layer with its checkout and its topic-filtered index; an untrusted owner's repository must be pinned to a commit one of its branches or tags reaches.

### Fixed

- `scripts/org-standards.sh` confines the org layer and every subscribed layer to its own checkout: a `standards_dir` or index `File` value that is absolute, has a `..` segment or resolves through a symbolic link outside the checkout is reported and dropped, and so are an org `REVIEW.md` or `.claude/standards.yaml` that resolves outside it and an org `REVIEW.md` line whose `<path>.md#<heading>` citation does. Every `.md` or `.markdown` citation on an org `REVIEW.md` line, a code span split across lines included, is checked as a reader would resolve it, and control characters, C1 included, in the printed criteria are escaped. A new `citations` command prints the citations a consumer may open, in every composition of the criteria: each single-backtick `<path>.md#<heading>` span that resolves to a regular file inside its own checkout, with its absolute path. `review` prints the criteria text alone, so no `REVIEW.md` text can add to them, and consumers open a `REVIEW.md` citation only from `citations`. Every org checkout writes a committed symbolic link as a plain file, so a path printed before a refresh never resolves outside the checkout afterwards, and an org cache that holds one or allows them is deleted without following a link and cloned again. `index` and `subscriptions` print a new index written under the reader's cache state, never inside a checkout, built only from the `standards-contract` version, the table header and each well-formed table row rebuilt from its cells, each `File` rewritten to the absolute path it resolves to inside the checkout; no prose or HTML is copied. Its clones, fetches, checkouts, `ls-remote` calls and lazy object fetches give up after `ORG_STANDARDS_GIT_TIMEOUT` seconds (default 60), and never prompt. Every git command it runs ignores the system and global git config except the user's proxy, CA, `core.sshCommand`, `url.<base>.insteadOf` and `credential.*` settings, so a private repository loads with the person's own credential helper or SSH key and no hook, fsmonitor, filter driver (git-lfs included) or template from that config runs, and a `trusted_owners` that is not a block list trusts no owner and is reported. A git command that needs no repository runs in the cache directory, reading no config of the repository the reader runs from, and no transport but `https`, `ssh`, `git` and `file` runs; a symbolic link at an owner directory or an entry of the cache is removed before the entry is read or built; and every value a report quotes has its control characters removed.
