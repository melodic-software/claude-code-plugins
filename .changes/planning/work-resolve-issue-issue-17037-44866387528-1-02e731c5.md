### Changed

- **Every `/planning:wayfind` destination now says when the map's dossier branch is deleted or reported.** A map that closes to a PRD or a plan hands on a `Source map: #<n>` line, which `/planning:prd` and `/planning:plan` copy into PRD.md and PLAN.md so `/work-items:decompose` can attach its work to the map and handle the branch. A map that closes to one change, a decision record or a general summary runs `/work-items:track dossier-branches` at map close, because those routes never create a container ([#17037](https://github.com/melodic-software/claude-code-plugins/issues/17037)).
