### Added

- `/corrections:codify count-checks [--since <day>] [--until <day>] [--bucket week|month]`: a read-only count of the checks merged changes record with a `Codifies:` line, per week or month and cumulative, read from default-branch git history only. Blocking checks lead, advisory checks have their own column, each rung that occurs has a column, and malformed, list-item, guidance-rung and reverted records are listed as not counted.
- A proposal for a checking rung or `make-impossible` now holds the `Codifies:` record line for the pull request body, and the task-list item form for work filed as an issue.

### Changed

- The enforcement ladder copy is at 3.1.0: the "Compiler or type settings" and "Tests" rows carry the rung ids `compiler-setting` and `behavior-test`.
