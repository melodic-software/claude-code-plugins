- **`codify reviews --pr <n> [--repo <owner/repo>]` mines one chosen pull request.** Open PRs and other repositories are included. The `review_mining_prs` window is not read and the distinct-PR threshold does not apply: every lesson goes on, labeled as from one pull request, and its proposal still waits for the person's approval.
