### Changed

- The find, improve and setup `evals.json` files are retired into the `evals/` case suite ([#8635](https://github.com/melodic-software/claude-code-plugins/issues/8635)). Twelve of the thirteen legacy cases become twelve new cases: `find-vague-ask-ranked-scan` (a vague ask routes to find, which walks every scan dimension, ranks rows carrying evidence, rung, size and value-to-effort, records gaps and asks for a pick), `find-targeted-quick-wins` (a prose narrowing to checkout and quick wins reads no unrelated module, ranks only small candidates and leads with instrumenting checkout), `find-unattended-files-capped` (a declared unattended run asks nothing, keys its report under the plugin data folder, skips the open duplicate and files at most two), `find-growing-clone-lint-proposal` (the 6-copy growing clone class outranks the 2-copy one and gets a lint proposal under `.work/improvement/<branch-slug>/`, with no gate on the total count), `imp-no-args-infers-from-conversation` (a bare improve after context recommends the target and focus it inferred and asks once), `imp-explicit-target-ships-one-commit` (an explicit target gets one standards fix with a file:line basis, checked before one commit), `ranked-options-ask-routes-to-find` (a ranked-options ask goes to find, not improve), `imp-unattended-throttle-stops` (an unattended run at three open improve pull requests stops without researching or editing), `imp-too-big-offers-slice-or-plan` (a change past the hard cap is offered as a smaller slice or `/planning:plan`), `setup-check-zero-config-info` (bare setup reports every absent layer as INFO with the bundled defaults), `setup-apply-drafts-then-asks` (apply shows the baseline, drafts exclusions and evidence sources, and asks before writing) and `setup-apply-verify-tracked-proposal` (the proposed team file holds churn keys only, both git probes run after it, untracked means commit it, and the recursive `.local` gitignore line is recommended). The thirteenth, the disconnected-capability scan, was already covered by `already-built-disconnected-scan`. Opening the pull request (improve), the below-throttle draft pull request (improve unattended) and fetching upstream guidance (improve currency focus) need the network, so those halves are not measured; nor are the real writes of the unattended report and the setup team file, which the sandbox denies. All three `evals.json` files are deleted.
