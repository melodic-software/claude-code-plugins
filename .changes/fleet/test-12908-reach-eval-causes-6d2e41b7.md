### Changed

- `/fleet:reach` says a `-p` receiver lives only as long as its turn, so a session that must stay up uses a background session, and that either one's standing instructions say what to do with each message and when to stop. It says to list first and message a name from the listing that shows it, and that a request naming a machine and not a lane lists each of that machine's lanes, since a listing shows only its own lane. From a PowerShell window it keeps the prompt in doubled single quotes and writes an apostrophe as `''\''''`, not `-p "..."`. The reach evals now create the condition each one measures, and their graders accept the correct reply forms they used to fail.
