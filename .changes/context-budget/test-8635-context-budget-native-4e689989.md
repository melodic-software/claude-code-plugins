### Changed

- The audit and setup `evals.json` files are retired into the `evals/` case suite ([#8635](https://github.com/melodic-software/claude-code-plugins/issues/8635)). Thirteen of the fifteen legacy cases become thirteen new cases: `au-baseline-report-from-record` (a baseline record's report carries the stamp and measured totals, and attribution candidates come only from its live tools list), `au-engine-error-relays-remediation` (an exit-3 error record yields no number, the measurement gap, and the SDK install line left to the operator), `au-deferred-only-saving` (a deferred-only saving is reported per bucket as request weight that leaves the context-usage headline unchanged), `au-bare-apply-prints-config` (a bare audit asked to apply a trim prints a bare-name `permissions.deny` entry and offers the ledger loop), `au-unused-plugins-routes-doctor` (unused plugins and MCP servers go to `/doctor`, with no usage-history scan), `au-aside-apply-names-fix` (an aside asking to apply trims names the explicit `fix` route and applies nothing), `au-fix-one-lever-at-a-time` (fix asked for three levers shows one exact diff and refuses the batch on attribution grounds), `su-bare-check-read-only` (bare setup runs the read-only check), `su-node-absent-both-dependents` (missing node FAILs with both dependents named), `su-toggle-true-hook-silent` (a true toggle with an unlaunchable exec-form hook is explained, not trusted), `su-sdk-install-request-declined` (a direct SDK install request is printed, never run), `su-two-clis-no-measure` (two CLIs are INFO with both stamps, and setup routes the measurement to the audit) and `su-headless-toggle-configure` (a headless toggle change routes to `claude plugin configure`, then the install rerun, never an uninstall). The other two were already covered and gain graders: `au-attribution-record-report` gains `listing-rule-explained` (the incomparable row's reason is explained: System tools deltas are valid only between runs with identical skill listings), and `au-fix-user-global-print-only` gains `classifier-reason` (the auto-mode classifier is the stated reason for print-only). Both `evals.json` files are deleted.
