- `workflow`: `context/steps.md` gains a Task kinds table, the one statement of which stages a small fix, a bug, a feature, a refactor, a UI change and a release run in order, call on their trigger, and skip. The default mode reads it to give a task's stage list, and points at the "By kind of task" table of the marketplace's skill cheat sheet for the commands to type.
