### Added

- `/session-flow:recall` reports a **Still reported** section: tracker items of an incident or user-report kind whose fix was reverted, that repeat the same symptom, or whose own text records a reopen, plus postmortems on the topic. Its tracker step now searches open and closed items through `/work-items:track search`, and a reverted commit that closes an item marks that item even when the tracker cannot be read.
- Two settings, resolved repository file over user option over default: `recall_report_kinds` (issue types or labels that count as an incident or a user report, default `Bug`) and `recall_doc_paths` (git pathspecs searched for postmortems, default `*.md`).
- Eval case `recall-still-reports-reverted-fix`: a closed bug whose fix was reverted shows under Still reported.
