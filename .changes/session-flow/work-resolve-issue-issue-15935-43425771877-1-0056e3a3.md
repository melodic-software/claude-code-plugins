### Changed

- `/session-flow:retro` now asks whether a check could decide a finding before it asks where the finding should live. If a check could, retro proposes a check, not a new prose rule. It sends the check to `/corrections:codify` when that plugin is installed, and otherwise to its catalog's Hooks section and the enforcement ladder. The catalog's target sections now run strongest first: Hooks, Settings, CLAUDE.md / Rules, then Memory. Retro proposes a CLAUDE.md or rules line only when no check on the enforcement ladder can decide the finding, or the check fails the ladder's guardrail criterion. The number of repeats before retro proposes a check now follows `/corrections:codify`'s `recurrence.min_occurrences` setting.
