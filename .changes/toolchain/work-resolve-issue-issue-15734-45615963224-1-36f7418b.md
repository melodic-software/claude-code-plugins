### Added

- `/toolchain:check --propose-records <dir>` drafts an ecosystem record in an unattended run from the run's `assumed:` lines, through a script in the check skill. The script re-reads each cited `file:line` and refuses a cited file that is untracked or changed from the merge-base with the default branch (or from `--base <ref>`), any command that line does not hold, an install verb, a package runner, a shell command string and a CI workflow file as the source. On a refusal it writes nothing, and it never writes inside an ecosystem records folder or over an existing file. The session then proposes the draft in a separate pull request.
- The same script's `verify` mode exits non-zero on any key or command in a record that the run's `assumed:` lines do not support. It requires `--base` and reads every cited line at that commit, the pull request's base, so a consumer's CI can check a lane's record pull request and no line the pull request adds can support it.
