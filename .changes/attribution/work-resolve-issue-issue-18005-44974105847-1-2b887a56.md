### Added

- **The per-user spend and depth dials are `userConfig` options.** `budgets.*`, `judge_samples` and `accuracy.*` each have an option of the same name with `.` written `_`, the layer below the team file. `sweep-ledger.sh` takes the fetch ceiling as `--user-config budgets.corpus_fetch_ceiling=N`, and `--show-config` names `userConfig` as its source. Every other key is a repository convention and stays in `<home>/attribution.yaml` or its personal override.

### Changed

- **`~/.claude/attribution.json` is retired, and still read while it exists.** The detectors read it below `userConfig`, so a new layer that sets a key wins. Each run prints one warning naming the file and where to move it. `/attribution:setup apply` previews each key and its new home and moves it after a yes. It checks that the new home resolves the same value before it deletes the old file. A later release stops reading the old path once no old file is reported.
