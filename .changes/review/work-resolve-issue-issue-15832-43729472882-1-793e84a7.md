### Added

- Bundled review criterion "Fail a change that loosens a check" (`skills/quality-gate/context/loosened-check.md`): a change that skips, focuses or deletes a test, changes an expected value to match the code, lowers a threshold, adds a suppression, sets a check to soft-fail, removes a check, raises a retry count or a test's own timeout, or edits a check's own code, runner, workflow or settings so it accepts more fails unless the spec names it and says why. A removal passes when the spec names it; a soft-fail passes only as a flaky test's quarantine with the spec's reason. Only spec text gives a reason, never the pull request body or comments. `/review:quality-gate`'s diff modes, the `code-reviewer` agent and `/review:fanout`'s criteria slices apply it when no project criterion covers the concern. A criteria file the change touches (renamed, copied, untracked, cited, an index pointing at criteria, or a path-scoped rule) counts only as its default-branch copy, both for that decision and for judging the diff, so a change cannot switch the check off or soften it for its own review.
- Settings `loosened_check_verdict` (`fail` or `note`, default `fail`, a policy floor) and `loosened_check_patterns` (path globs or `text:` patterns, the union of every layer), each a user option and a `docs/conventions/review.yaml` key read from the default branch, resolved by `scripts/loosened-check-settings.mjs`.
- The `fanout-sweep` workflow takes `loosenedCheck` (the criterion's path, which every slice or model tier then reads) or `loosenedOverride` (the `.md` project document that replaces it, decided once per run), requires exactly one of them and dispatches nothing otherwise, and returns which applied as `loosened`. It also takes `loosenedSettings` (the criterion's two resolved setting lines, given to every slice and named leaf), `defaultRef` (where a slice reads a criteria document the change touches) and `spec` (the issue text, quoted as data in every leaf prompt). `/review:fanout` resolves the settings and the decision in both review modes.
- Seven eval cases for the criterion's verdicts, and a criterion-citation grader on the lowered-coverage case.
