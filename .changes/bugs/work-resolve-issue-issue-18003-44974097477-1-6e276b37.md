### Added

- A `gotchas_file` `userConfig` option names your own Markdown file whose `## Gotchas` section `/bugs:scan` and `/bugs:write` read in every repository, in place of `~/.claude/bugs.md`.
- Retirement record `bugs-r001` (`retirements.yaml`, with the shared `lib/check-retirements.sh`) declares the old `.claude/bugs.local.md`. `/bugs:setup check` names each old config file it finds, and `/bugs:setup apply` moves its settings to the new location after a preview and a yes, checks the new location resolves the same values, then deletes the old file.

### Changed

- The personal override moves from `.claude/bugs.local.md` to `docs/conventions/bugs.local.md`. `concat-gotchas.sh` takes the option's file as `--user-file`, labels each block by its layer, and while an old file (`~/.claude/bugs.md` or `.claude/bugs.local.md`) exists it still reads it wherever the new file is absent and prints one warning per old file naming the new location and `/bugs:setup apply`.
