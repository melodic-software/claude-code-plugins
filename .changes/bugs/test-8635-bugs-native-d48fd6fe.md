### Changed

- The scan, setup and write `evals.json` files are retired into the `evals/` case suite ([#8635](https://github.com/melodic-software/claude-code-plugins/issues/8635)). Nine new cases: `sc-fix-and-file-request-read-only` (asked to file and fix while scanning, a dry run edits, branches and files nothing, says filing needs `--track`, and hands the fix to a lane), `sc-routes-known-issues-and-pr-review` (a known-issues question goes to `harness-ops:known-issues`, a pre-merge diff to the review lane, and no hunt starts), `sc-lens5-member-card` (a rendering target gets Lens 5, and its hardcoded plural is a verified finding, not a formatting opinion), `sc-rate-limiter-no-lens5` (a target that renders nothing gets no Lens 5), `su-check-commit-reports-native-route` (a request to commit reports gets the repository's own report directory and Claude Code's plugin configuration, never a settings edit), `su-apply-writes-team-lanes` (apply writes only `docs/conventions/bugs.yaml`, in the documented keys, then re-checks it), `su-apply-output-dir-routes-native` (apply routes `output_dir` to Claude Code and recommends the ignore line without editing `.gitignore`), `su-check-layer-provenance` (check reports each layer, names `lanes: []` as an opt-out and gives `filing_posture` its layer) and `wr-typo-identifier-asks` (a misspelled symbol gets one question, not a silent rename). `sc-planted-bug-dry-run`, `wr-five-fields-late-fee`, `wr-unbacked-repro-placeholder` and `wr-no-bug-confirmed` gain graders for the legacy expectations they missed, and `bug-report-motion-drawer-jump` gains the Bash grant its slash command needs to load. The rotation, `--track` filing and named-lane cases are held: each reads or writes the plugin data directory, which an eval run refuses. All three `evals.json` files and the unused pagination fixture are deleted; the two scan fixtures move to `evals/fixtures/`.
