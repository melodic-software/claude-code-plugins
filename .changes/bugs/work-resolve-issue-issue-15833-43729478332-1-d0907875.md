### Changed

- `/bugs:scan` now treats a run as unattended when `--unattended` is passed or the environment says nobody is present (`CLAUDE_CODE_REMOTE` set, `claude -p`, an autonomous loop). Before, only the flag counted. An unattended run runs none of the scanned code.
- The rule for running scanned code, the evidence labels and the verification gate's prompt now live in `reference/run-reviewed-code.md`, a generated copy of the marketplace contract `docs/contracts/run-reviewed-code/` that the review plugin shares. `skills/scan/context/verification-gate.md` points at that file instead of keeping its own wording. The gate's verdicts and return shapes are unchanged.
