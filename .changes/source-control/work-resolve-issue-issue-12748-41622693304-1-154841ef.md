### Changed

- babysit-loop: the rung partition reads no work class. A PR is merge-eligible when the effective
  rung is merge-capable and the cells that rung needs are effective-promoted, by the merge gate's
  rung-to-cell map (`c2-mechanical` needs `C2-auto-merge`; the C3 rungs need every cell). An item
  with no `work-class:` label, or a structural one, partitions like any other; the
  untrusted-provenance hold, the fork and trust tests, the do-not-merge, parked and human-feedback
  withholdings, the grace window and the head-SHA pin stay. The diff check no longer feeds a
  class into the rung test; a diff that cannot be read still holds the PR.
- `publish-promotion-evidence.mjs` counts each autonomous merge toward the cells of the rung it
  merged under, read as `merge.rung` in `docs/conventions/pr-pipeline.yaml` at the merge commit's
  first parent, and a human merge toward `C3-ai-review-blocking` only. A merge whose rung does not
  read as merge-capable is listed in `unattributedAutonomous` (formerly `unclassedAutonomous`):
  its contrary events go against every cell and it counts toward no positive term. The report's
  term names follow the rungs (`autonomous merges`, `merge-reviewed merges`,
  `advisory AI reviews`). An events file published under the class attribution can hold events
  this one no longer derives, and publishing over it refuses; starting a new file is the
  operator's call.
- Breaking, and how to migrate:
  - A babysit loop at `c2-mechanical` or a C3 rung now merges pull requests with no `work-class:`
    label, and structural ones, once the rung's cells are effective-promoted. Before upgrading,
    lower `merge.rung` or label the pull requests the loop must not merge `do-not-merge`.
  - A script or dashboard that reads the publisher's report JSON must read
    `unattributedAutonomous` in place of `unclassedAutonomous`, and the new term names in `cells`
    (`autonomous merges`, `merge-reviewed merges`, `advisory AI reviews` and the rest) in place of
    the class-named ones.
  - A scheduled `publish-promotion-evidence.mjs --out <dir>` over an events file this plugin's 6.x
    releases published can exit 1 with `drop N previously published event(s)`. Point `--out` at a
    new directory, or move the old file aside, and publish again.
