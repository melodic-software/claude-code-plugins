### Fixed

- `/source-control:pull-request ready` takes the head it waits on and flips from local `git rev-parse HEAD` instead of reading it from GitHub right after the review-fix push. GitHub could still return the pre-push head, so the wait for the push's CI run was skipped and the guarded `verify-gate.sh check` refused the flip for a commit with no verify record. A new `ready-flip.test.sh` runs the wait and flip blocks against a forge that lags one read behind.
