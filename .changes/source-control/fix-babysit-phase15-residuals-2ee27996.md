### Security

- The unattended merge path (`babysit_merge.py --unattended`) closes residuals from #7339 before Phase 15 enables it. A binding, probe root, evidence source or checker the lane user can write, or replace through any directory above it, refuses promotion like a writable settings file, and every worktree of the checkout reaches the promotion resolver as a `--worktree-root`. A head commit whose author or committer is linked to no account, or a head with more commits than the 250 the commits list returns, refuses as `head-pusher-unproven`. Only an owner, member or collaborator's blocking comment dequeues a queued entry. The opt-in label is read again, presence and provenance, beside the second kill-switch read. A queued pull request this run scores MED or HIGH, or finds on a base that is not the default branch, leaves the queue. A failed dequeue no longer stops the others, and the queue read passes the branch as a raw string (`-f`).

### Fixed

- The unattended merge gate called `resolve-promotion-evidence.mjs` with the retired `--binding`, `--probe-evidence-root`, `--evidence` and `--checker` flags, so every promotion read failed closed as a usage error. It now passes only `--checkout`, one `--worktree-root` per worktree and, after a demotion record, the new `--window-start <ISO 8601>`: the resolver hands the checker a temporary copy of the evidence source with one `gate-failure` per promotable cell at that instant, and fails closed on an empty or malformed value or a source that is not a JSON array. The gate then refuses any option value, or settings file it came from, that the lane user can write.
