### Security

- The unattended merge path (`babysit_merge.py --unattended`) closes residuals from #7339 before Phase 15 enables it. A binding, probe root, evidence source or checker the lane user can write, or replace through any directory above it, refuses promotion like a writable settings file, and every worktree of the checkout reaches the promotion resolver as a `--worktree-root`. A head commit whose author or committer is linked to no account refuses as `head-pusher-unproven`. Only an owner, member or collaborator's blocking comment dequeues a queued entry. The opt-in label is read again, presence and provenance, beside the second kill-switch read. A queued pull request this run scores MED or HIGH, or finds on a base that is not the default branch, leaves the queue. A failed dequeue no longer stops the others, and the queue read passes the branch as a raw string (`-f`).
