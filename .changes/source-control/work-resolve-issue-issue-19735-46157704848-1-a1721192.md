### Added

- `worktree-claim.sh take <path> --session-id ID` takes a worktree for a session in one call. It claims an unlocked tree, keeps the session's own lock, refuses a lock with no reason or a claim that is not provably stale, and takes over a stale claim. When the branch is `[gone]` upstream, it replaces the stale claim with a new one.

### Changed

- `worktree-create.sh` now reuses an existing worktree through `worktree-claim.sh take`, so both scripts take over a stale lane lock that names no session. Before, `worktree-create.sh` refused it.
