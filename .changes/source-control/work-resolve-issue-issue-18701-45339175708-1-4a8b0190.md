### Added

- The `ready` action's hold check (`check-ready-holds.sh`) reads `trusted_actors_source` from `docs/conventions/source-control.yaml` on the default branch before it trusts an eval-only `do-not-merge` hold. With `standards`, it reads the trusted-actors list from `melodic-software/standards` at the commit that repository's `main` names. Unset or `repository` reads the repository's own `.github/standards/` copy, as before. Any other value keeps the label holding the flip, as does a conventions file, standards commit or list the check cannot read.
