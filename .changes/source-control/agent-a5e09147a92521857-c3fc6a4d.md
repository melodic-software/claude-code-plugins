### Fixed

- `cost_decision` binds an owner cost decision to one pull request and the head it decided: a `**Decision recorded.** Cost:` comment on the pull request, or one on its linked issue (closing, else the one `Refs:` issue) that names the pull request as `#<number>` (not `owner/repo#<number>`, `&#<number>` or `##<number>`), covers the head of the latest review-lane cost hold marker before it (for one on the pull request with no marker, the last push before it), and a later head only when every change since is a merge of the base: the pull request's net change against the base, file by file, is the same at both. A decision recorded on that issue for another change no longer clears the cost hold of a pull request that links the issue later, and a commit after the decision needs a new one.
