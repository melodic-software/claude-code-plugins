### Changed

- **The audit's Read-deny scope covers `cp` and `mv` from Claude Code 2.1.321.** `reference/required-permissions.md` reports deny rules and protected-file prompts as reaching the file a `cp` or `mv` into a directory writes, and a path-spelled `cp` or `mv` as checked like the bare command, on 2.1.321 and later; whether a `Read` deny covers the file a `cp` or `mv` reads stays unverified. The sandbox section also reports a sandbox on a client older than 2.1.321 as partial, because a read-only Bash command could run outside it unprompted ([#14843](https://github.com/melodic-software/claude-code-plugins/issues/14843)).
