### Added

- the `lint` entry skips generated files

  A file whose first 5 lines match `@generated`, `<auto-generated` or Go's
  `// Code generated ... DO NOT EDIT.` line is not passed to typos, judged on
  the staged copy at commit time and the work tree at turn end. The multi-valued
  git config key `spelling.generatedHeader` adds markers without a tracked file.
  `--resolve` reports a skipped file as not governed, naming the marker, and the
  refusal message names the key.
