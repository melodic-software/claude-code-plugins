### Changed

- The audit and setup `evals.json` files are retired into the `evals/` case suite ([#8635](https://github.com/melodic-software/claude-code-plugins/issues/8635)). Nine new cases: `audit-unscoped-cost-gate` (a bare whole-repo request asks for a scope, names the per-file fan-out cost, and dispatches nothing), `audit-review-only-stops` (`--review-only` reports, hands off to no remediation skill, writes no file and stays on the named file), `audit-infers-and-offers-setup` (with no config the audit looks for one before discovery, says it is absent, audits what the repo holds and offers `/codebase-health:setup` without writing a config), `audit-settings-schema-routes-out` (settings and `.mcp.json` schema drift is reported out of scope and routed to `/harness-config:audit`, never claimed available or fanned out), `audit-view-team-terminal` and `audit-view-retired-terminal` (a terminal medium from the team file or the retired `~/.claude/rendered-views.md` prints the resolver's line and notice with no view offer), `audit-view-publishing-ignored` (publishing values in the team file and the retired file are only noticed, never followed), `setup-apply-interviews-first` (apply explores and asks with a recommendation before writing) and `setup-apply-keeps-existing` (apply reads the existing config and keeps its custom dimension). `audit-planted-drift` gains the table header, severity, confidence, enforcement, config-gap, resolver-line, view-unavailable and no-HTML-write graders, and `audit-fix-delegates` gains the not-installed manual handoff and report-before-handoff graders. The shared fixture gains `drift-docs-tree`, `harness`, three `view-*` and two `setup-*` modes; the `view-*` and `setup-*` modes make the workspace its own repository, and a file under `$HOME` is written only when it is not the real home. The legacy view-offer lines need the visualization plugin loaded and the offer-taken lines (no `artifact` passed) a second user turn, so neither is measured; with the plugin absent the cases grade the one-line unavailable note instead. Also, setup's actual config write is unmeasured because an eval run denies writes under the workspace's `.claude/`. Both `evals.json` files are deleted.
