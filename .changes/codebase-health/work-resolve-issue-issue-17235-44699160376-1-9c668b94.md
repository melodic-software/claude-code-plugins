### Added

- **Several repositories in one run.** `/codebase-health:audit` now accepts the target-scope forms (`--repo`, `--repos-from`, `--owner`, `--fleet`, `--skip`) and runs once per repository. Each repository is read from its own tree, with its own rules, config and verification level. A claim in one repository about another repository in scope (a path, a version, a workflow it calls) is checked against that repository. Findings from all repositories go into one report. Cross-repository file copies are left to `/coupling:reduce`, which the report names. `--fix` suggests `/implementation:implement` then `/verification:confirm` for each repository with findings, run from that repository's own worktree. With no target form the skill behaves as before. The plugin now ships `reference/target-scope.md`, a generated copy of the contract ([#17235](https://github.com/melodic-software/claude-code-plugins/issues/17235)).
