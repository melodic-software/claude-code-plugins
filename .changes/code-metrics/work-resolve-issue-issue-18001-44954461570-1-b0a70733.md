### Changed

- **The personal override moves to `docs/conventions/code-metrics.local.yaml`** ([#18001](https://github.com/melodic-software/claude-code-plugins/issues/18001)), beside the team file, per the config-cascade layers. The plugin declares no `userConfig` option, so there is no user-global file layer. Recommended `.gitignore` line: `docs/conventions/**/*.local.*`.
- **Dual-read window for the old paths.** `~/.claude/code-metrics.yaml` is still read below the team file, and `.claude/code-metrics.local.yaml` is still read as the personal layer while the new file is absent. Each run prints one warning per old file naming where its keys go; with both personal files present the new one wins and the warning names both. A later release stops reading the old paths.

### Added

- **`/code-metrics:setup apply --copy-old`** copies the old personal files into `docs/conventions/code-metrics.local.yaml` after a `--preview` and a yes, naming each key it copies or skips and leaving the old files in place. A key of the old user-global file that the team file sets is not copied, so the effective configuration does not change. `/code-metrics:setup check` names each old file it finds.
