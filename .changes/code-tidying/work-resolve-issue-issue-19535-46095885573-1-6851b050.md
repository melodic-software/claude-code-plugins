### Changed

- **`audit-dead-code` eval fixtures no longer give away their verdicts.** The `dead-and-dynamic.*`, `py-entry.py`, `ts-entry.ts`, `ts-used.ts` and `ts-orphan.ts` fixtures dropped the comments that named which symbols are dead, alive or entry points, so an eval run has to reach each verdict from the capture and the code. The canned knip, vulture and gopls captures and the scan test follow the new line numbers. The JS/TS grep figures in `SKILL.md` and `context/analyzers.md` now read 4 candidates over the trap corpus, 75% precision and 100% recall, because no comment spells `formatLegacyRow` any more.
