### Changed

- The methodology and simulation `evals.json` files are retired into the `evals/` case suite ([#8635](https://github.com/melodic-software/claude-code-plugins/issues/8635)). Thirteen of the seventeen legacy cases become thirteen new cases: `methodology-whole-domain-start` (whole-domain discovery starts broad with Big Picture and names both the facilitation and the simulation paths), `methodology-run-request-routes` (a request to run an agentic simulation routes to `/event-storming:simulation` and places no stickies), `methodology-bare-skips-boards` (with no Miro, board discovery is skipped without an error and the goal question is asked), `methodology-brandolini-wins-conflict` (a practitioner ordering is an enrichment and Brandolini's order stands), `methodology-notation-slash` (`--notation` gives the color mapping without the discovery questions), `methodology-unsure-asks-first` (an unsure user gets clarifying questions, not a format), `simulation-markdown-big-picture-first` (a structured-markdown plan opens with Big Picture and 4 to 7 personas), `simulation-board-url-needs-miro` (a board URL needs Miro and does not degrade to markdown), `simulation-no-auto-advance` (after Big Picture the user picks the next context), `simulation-state-under-plugin-data` (run state goes under the plugin data directory, never the install directory or the project), `simulation-default-domain` (`--simulate` alone defaults to Developer Conference and offers the markdown path), `simulation-design-level-needs-pm` (Design-Level looks up the run history, offers `--process-model` first and fabricates no model) and `simulation-discover-bcs-export` (a supplied board export gets the six-heuristic table with evidence, short names, the Enrollment divergence and the refund winner as the next target, with no Miro ask). `simulation-miro-absent` gains graders for the markdown path as the default, the install-Miro alternative and no claimed stickies. The board export fixture moves to `evals/fixtures/`. Not measured: three legacy cases (two need a live Miro server, one delegates to another plugin's skill), the live-board path of the simulate case, the Design-Level case's report that no Process Modeling board exists (simulation 7 expectation 2's positive half, `surfaces-missing-prereq`), which the run cannot check because it cannot read the plugin data directory, and the unsure user's recommendation once they answer, which needs a second turn. Both `evals.json` files are deleted.
