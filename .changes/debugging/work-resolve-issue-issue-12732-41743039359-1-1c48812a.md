### Added

- A `medium` plugin option, the per-user scope the shared medium resolver reads for the post-mortem view. It defaults to `auto`, a local file as before. The option declares a fixed list of values, so the debugging plugin now needs Claude Code v2.1.271 or later.

### Changed

- `/debugging:debug`'s post-mortem view now resolves its destination through the shared medium resolver (`--lane debugging:debug`) and prints the resolver's report and notice lines ([#12732](https://github.com/melodic-software/claude-code-plugins/issues/12732)). The skill no longer reads the `rendered-views` files itself: set the preference in `docs/conventions/rendered-views.yaml`, its `.local.yaml` personal override, or the plugin's `medium` option.
- The rendered-view procedure moved from `skills/debug/reference/rendered-view.md` to `reference/rendered-view.md`, where the other view lanes keep their copy.

### Removed

- A publishing `medium` (`artifact` or `hosted`) in `~/.claude/rendered-views.md`, `.claude/rendered-views.md` or `.claude/rendered-views.local.md` no longer publishes the post-mortem view. The resolver prints a notice naming where to set the value now, and the other scopes or the lane's local-file default decide instead.
