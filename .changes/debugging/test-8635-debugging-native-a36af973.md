### Changed

- The debug and analyze-profile `evals.json` files are retired into the `evals/` case suite ([#8635](https://github.com/melodic-software/claude-code-plugins/issues/8635)). Debug 1-7 were already cases; twelve new ones cover the rest: `belief-checked-before-third-fix` (two failed fixes name their shared belief and check it with the loop before a third), `uneven-load-gets-tally-script` (a per-worker tally runs on each replay pass and points at the worker-picking code, never the memory limit), `failure-after-restart-suspects-stale-state` (after a reboot the left-behind state ranks above code and is moved aside one file at a time), `ruled-out-edits-dropped-before-commit` (edits for a ruled-out hypothesis come out before the fix commit), `diagnosis-only-stops-at-confirmed-hypothesis` (a diagnosis request stops at file:line with no fix or test), `check-shaped-prevention-routes-to-owner` and `check-shaped-prevention-without-owner-plugins` (a check-shaped prevention goes to `/corrections:codify` or the issue tracker and is never built), `minimize-red-loop-before-hypotheses` (a red request is cut one element at a time before any hypothesis), `forced-red-diff-against-pristine-copy` (a forced red is diffed against the committed fixture first), `human-driven-loop-keeps-sign-in-out-of-ask` (sign-in stays an instruct step and no ask collects a secret), `analyze-profile-heapsnapshot-retaining-path` and `analyze-profile-minified-frame-needs-source-map`. `load-mode-stops-at-mechanism` gains the mktemp, 5-of-7-samples, caller-path and no-write-under-src graders. The py-spy dump fixtures move to `evals/fixtures/`, and the two `evals.json` files are deleted.
