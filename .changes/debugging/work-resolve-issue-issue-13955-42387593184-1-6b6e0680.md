### Fixed

- `/debugging:debug`'s post-mortem view passes `""` to the medium resolver when the `medium` option reads empty or unsubstituted, and never puts a `${user_config.*}` string in a shell command, which a non-interactive run refused ([#13955](https://github.com/melodic-software/claude-code-plugins/issues/13955)). A new `builds-post-mortem-view-on-request` eval case covers the build path: the reader asks for the view, the resolver runs with `--lane debugging:debug` and no `${user_config.*}` string, and `build-view.mjs` builds the page.
