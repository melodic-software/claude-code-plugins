### Added

- control-claude-code's `cli/account.mjs` handles API-key auth. When `claude auth status --json` reports `authMethod` `api_key` with no email and no organization, it prints the one line `none: API-key auth has no signed-in account` and exits 0 ([#13760](https://github.com/melodic-software/claude-code-plugins/issues/13760)). Drive's contract defines no `none:` output for a `values:` source, so its mask post-check reads that line as one literal value to scan for. Any other auth method with no email or organization still exits 1 with nothing on stdout.
