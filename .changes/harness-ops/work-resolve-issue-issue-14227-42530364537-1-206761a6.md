### Added

- A repository can route its hook producers through the reference sink with no copy of it: set `HOOK_TELEMETRY_SINK` to `.observability/claude/hook-telemetry-sink.sh` (or `<session_event_log_dir>/hook-telemetry-sink.sh`) in its `settings.json`, and the new SessionStart hook `hooks/hook-telemetry-launcher.sh` writes a launcher there that runs the installed sink. The launcher goes under the repository root, even for a session started in a subdirectory, and the hook needs `node` like the plugin's other hooks. It sits under the log root's self-ignoring `.gitignore`, is rewritten when a plugin update moves the install, and carries `session_event_log_dir` and `hook_events_max_bytes` to producers in other plugins. Any other `HOOK_TELEMETRY_SINK` value writes nothing.

### Fixed

- The reference sink fills `subject` from `data.file` when the envelope has no `data.subject`, so rows from guardrails and the formatters, whose data is `{tool, file}`, no longer land with an empty subject.
- The README's copy route lists all three files the sink needs: `hook-telemetry-sink.sh`, `hook-utils.sh` and `session-log-lib.sh`.
