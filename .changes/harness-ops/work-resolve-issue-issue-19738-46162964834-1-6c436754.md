### Changed

- `/harness-ops:plugins` reads and orders plugin versions through one jq module, `scripts/version.jq`. `fleet-state.sh`, `converge-plan.sh` and `sync-run.sh` include it instead of keeping their own copies. `sync-run.sh` takes each move's direction from the module's `version_direction` instead of a separate bash compare, and the `SYNC_RUN_VERSION_DIRECTION` test hook is gone.
