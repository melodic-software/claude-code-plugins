### Fixed

- **The pre-commit check re-stages the PowerShell files it rewrites without putting their paths on git's command line.** With many staged PowerShell files, that list could pass the 32,767-character Windows command-line limit, and the rewritten files were then left unstaged. The shared `check-lib.sh` helper `checks_restage` now lists the unstaged changes once and gives `git add` the paths on stdin, which needs git 2.25 or later. A failed git call there now fails the hook instead of passing.
