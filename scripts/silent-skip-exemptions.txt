# Quiet skips scripts/check-silent-skips.sh accepts, each with the reason no
# notice is shown. Every other site that gate flags must make its skip visible.
#
# Format: one `<path> <guard>  <reason>` per line. <path> is repository-relative.
# <guard> is the tool after `command -v` for a hook guard (same-line or block),
# or the double-quoted message of an `ok "skip ..."` in a scripts/*.test.sh.
# The reason is the rest of the line, and an entry with none fails. No line
# number is recorded, so an entry survives the guard moving within its file.
# Whole-line `#` comments and blanks are ignored; the file is parsed by
# scripts/lib/read-list.sh in `leading` mode.
#
# Checked against the scan: an entry that matches no flagged quiet site (the
# guard is gone, renamed, or now shows a notice) fails as stale, so the list
# cannot outlive what it excuses.
