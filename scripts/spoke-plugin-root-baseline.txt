# directory. One `<repository-relative file path> <occurrence count>` per line,
# the count summing both tokens; a `#` starts a comment. Keyed on file.
#

# model verbatim. The fix: SKILL.md renders <skill-dir> from ${CLAUDE_SKILL_DIR}
# and the spoke cites <skill-dir>/scripts/..., as plugins/harness-memory does.

# listed with a trailing `# justified: <reason>` comment. A file whose hits name
# a path the model is meant to run or read carries `# pending: <fix>` until it
# is fixed.
#

# or holds a different count fails the gate. Never add an entry for a new spoke:
# use <skill-dir> instead.
