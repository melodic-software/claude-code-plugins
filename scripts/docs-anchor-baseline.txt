# The rule: .claude/rules/skill-bodies-state-current-rules.md. A docs-page
# pointer links the section it rests on (`<url>#<section>`); an upstream issue
# or a probe needs no anchor.
#
# Each row is a file's count of lines carrying such a link. A file over its row,
# or with no row, prints an `advisory:` line per link and does not fail.
#
# The list can only SHRINK: the validator FAILs on a row whose count is now
# lower (lower the row), zero, or whose file is gone (remove the row). Never add
# a row or raise a count to quiet an advisory: link the section instead.
#
# Format: `<repo-relative path> <line count>`, optionally followed by `# note`.
# Blank lines and `#` lines are ignored.
