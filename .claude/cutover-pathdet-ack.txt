# "locates a path by its existence", and that distinction is the condition, so
# the judgment lives here where it can be reviewed.
#
# One row per acknowledged PATHDET row, tab-separated:
#
#   <path>	<the trimmed source line>	<one-line reason it survives cutover>
#
# Matching is on path plus exact source text, never line number: a row that
# moves still matches, and a row whose code changed falls out and has to be
# re-reviewed. A PATHDET row with no row here is [UNMET] and is named in the
# check's output. No path convention exempts anything, test trees included.
