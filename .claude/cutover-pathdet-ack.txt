# Reviewed acknowledgements for the AGENTS.md cutover's path-detection rows.
#
# Read by plugins/instruction-placement/skills/migrate/scripts/cutover-check.sh,
# graded condition 4: no repository locates a path by the existence of
# CLAUDE.md. A grep cannot tell "reads CLAUDE.md as an instruction file" from
# "locates a path by its existence", and that distinction is the condition, so
# the judgment lives here where it can be reviewed.
#
# One row per acknowledged PATHDET row, tab-separated:
#
#   <path>	<the trimmed source line>	<one-line reason it survives cutover>
#
# Matching is on path plus exact source text, never line number: a row that
# moves still matches, and a row whose code changed falls out and has to be
# re-reviewed. A row with an empty reason acknowledges nothing; the reason is
# the review. A PATHDET row with no row here is [UNMET] and is named in the
# check's output. No path convention exempts anything, test trees included.
#
# This repository is deliberately NOT at [MET]. One row is outstanding:
# claude-memory's discover-instruction-surfaces.sh:159. That script has no
# AGENTS.md handling at all (grep AGENTS over it returns nothing), so after
# cutover it would emit no project instruction-surface row and the audit would
# report a repository with instructions as having none. It is a real blocker,
# it is fixed in claude-memory rather than acknowledged here, and until then
# this repository honestly reports condition 4 unmet.
