# Reviewed acknowledgements for the AGENTS.md cutover's path-detection rows.
#
# Read by plugins/instruction-placement/skills/migrate/scripts/cutover-check.sh,
# graded condition 4: no repository locates a path by the existence of
# CLAUDE.md. A grep cannot tell "reads CLAUDE.md as an instruction file" from
# "locates a path by its existence", and that distinction is the condition, so
# the judgment lives here where it can be reviewed.
#
# One row per acknowledged PATHDET row, tab-separated:
#
#   <path>	<the trimmed source line>	<one-line reason it survives cutover>
#
# Matching is on path plus exact source text, never line number: a row that
# moves still matches, and a row whose code changed falls out and has to be
# re-reviewed. A tab inside a source line is compared as a space, because a
# tab-separated file cannot otherwise express such a row. A row with an empty
# reason acknowledges nothing; the reason is the review. A PATHDET row with no
# row here is [UNMET] and is named. No path convention exempts anything, test
# trees included.
#
# The scan reports any existence-ish mention of the name in a code file rather
# than a fixed list of spellings, so prose in an eval file lands here too. That
# is the safe direction: a miss clears a cutover that breaks a repository, and
# a false positive costs one line in this file.
#
